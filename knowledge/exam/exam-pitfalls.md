# 华为机考避坑清单

> 2025 年 OD/校招高频踩雷点，来自牛客 HR/过来人帖。**考前 1 小时对照检查。**

## 双机位（重灾区）

### 第二机位（手机）

| 坑 | 正确做法 |
|----|----------|
| **断连无弹窗** | 系统不会提醒！以为在录其实早断了 → 成绩可能无效 |
| 画面不全 | 必须同时拍到：**屏幕 + 键盘 + 上半身** |
| 息屏/锁屏 | 关自动锁屏，**插电**，必要时开飞行模式 + WiFi |
| 来电/闹钟/微信视频 | 开免打扰，清后台 |
| 断连后果 | 截图变少 → 过不了系统筛选 |

### 第一机位（PC）

| 坑 | 正确做法 |
|----|----------|
| 脸不在画面 | 全程露全脸，别长时间低头 |
| 摄像头冲突 | 关虚拟摄像头、录屏软件、其他占用摄像头的程序 |
| 浏览器 | 最新版 Chrome，提前重启电脑 |

## 答题流程

| 坑 | 正确做法 |
|----|----------|
| 死磕一题 | 先 **1 分钟扫三题**，有思路的先做 |
| 第三题切换 | OD 部分场次：**切到最后一题后不能回到前两题**（谨慎切换） |
| 不点保存 | 必须点 **「保存并调试」**，否则可能丢内容 |
| 追求满分 | 150 即过，前两题 80%+70% 第三题 0 分也可能过 |
| 完全不会 | 写一行/暴力也要提交，按比例拿分 |

## 作弊与合规

| 禁止 | 说明 |
|------|------|
| 切屏搜题 | 切屏次数超限可能直接失效（有帖称 3 次失效、5 次自动交卷） |
| 百度/Google | 可能被判定作弊 |
| 代码高重复率 | 勿抄他人代码 |
| IDE 留大量刷题代码 | 粘贴时留意监控 |

## 环境与意外

- 断网/断电：可关浏览器重开链接继续（以当时指引为准）
- 链接 **7 天有效**，别拖过期
- 遇到问题及时联系 HR
