# 华为机考避坑清单

> 2025–2026 校招/实习机考高频踩雷点，来自牛客与校招过来人帖。**考前 1 小时对照检查。**（本库只覆盖校招/实习渠道，不含华为 OD 社招渠道。）

## 双机位（重灾区）

### 第二机位（手机）

| 坑 | 正确做法 |
|----|----------|
| **断连无弹窗** | 系统不会提醒！以为在录其实早断了 → 成绩可能无效 |
| 画面不全 | 必须同时拍到：**屏幕 + 键盘 + 上半身** |
| 息屏/锁屏 | 关自动锁屏，**插电**，必要时开飞行模式 + WiFi |
| 来电/闹钟/微信视频 | 开免打扰，清后台 |
| 断连后果 | 截图变少 → 过不了系统筛选 |

### 第一机位（PC）

| 坑 | 正确做法 |
|----|----------|
| 脸不在画面 | 全程露全脸，别长时间低头 |
| 摄像头冲突 | 关虚拟摄像头、录屏软件、其他占用摄像头的程序 |
| 浏览器 | 最新版 Chrome，提前重启电脑 |

## 答题流程

| 坑 | 正确做法 |
|----|----------|
| 死磕一题 | 先 **1 分钟扫三题**，有思路的先做 |
| 不点保存 | 必须点 **「保存并调试」**，否则可能丢内容 |
| 追求满分 | 以当期通过线为准（常见 200 分），前两题稳拿、第三题争取部分分 |
| 题目切换 | 以当场考试系统规则为准；不确定时先扫题再动刀，避免误操作不可逆切换 |
| 完全不会 | 写一行/暴力也要提交，按比例拿分 |

## 作弊与合规

| 禁止 | 说明 |
|------|------|
| 切屏搜题 | 切屏次数超限可能直接失效（有帖称 3 次失效、5 次自动交卷） |
| 百度/Google | 可能被判定作弊 |
| 代码高重复率 | 勿抄他人代码 |
| IDE 留大量刷题代码 | 粘贴时留意监控 |

## 环境与意外

- 断网/断电：可关浏览器重开链接继续（以当时指引为准）
- **别搞错开考时间**：国内常见为**每周三晚 19:00–21:00**；留学生渠道不一定每周都有，可能与国内合并，或单独在部分周的**周四上午 9:00–11:00**（以邮件为准）
- 遇到问题及时联系 HR
