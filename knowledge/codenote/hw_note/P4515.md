# Offer入职时间

**暑期实习**

**Offer的入职时间取决于你什么时候拿Offer。此外实习入职没有体检，秋招才有**

案例1：26年群友在4月初拿Offer，可以到6月份入职

案例2：25年群友投的晚，机考的晚，6月份才拿Offer，可以7月份入职

**秋招**

Offer的入职时间需要在内部软件上预约。有6月，7月，8月可以选。

# 入职后的转正与升职

　　 **这里的”转正“是指入职之后的转正考核**，而不是暑期实习的转正。华为暑期实习没有转正名额！

# 可信考试介绍

　　华为设有一套专门针对员工的考试体系，称为“可信考试”，共包含四门科目（科目1、2、3、4），考察内容见下表。并且它分为三个等级：入门级、工作级和专业级，难度依次递增。该考试在公司内部具有重要地位。

　　**新员工转正要求**：公司设有试用期，转正需通过“工作级”考试。未通过不会被辞退或降薪，但无法享受转正员工的全部福利，例如周末加班费等。

　　**升职晋级依据**：可信考试成绩是升职加薪的重要参考。一般来说，只有通过“专业级”考试，才有资格参与职级晋升评定。

　　**持续性要求**：可信考试为年度考核项目，必须每年参加，并非一次通过即可永久有效。

　　此外，所有科目每季度最多考2次，科三一年最多考5次，科目二，四一年最多考4次。科目一一年最多考3次。

| 科目   | 考察内容                                 |
| ------ | ---------------------------------------- |
| 科目一 | 上级编程，LeetCode算法题                 |
| 科目二 | 编程知识与应用，考察基础的编程语法知识等 |
| 科目三 | 安全编程、质量、隐私，还有开发者测试等   |
| 科目四 | 重构知识，包括设计模式、代码重构等       |

# 如何准备可信考试
　　在讲完可信考试的重要性之后，接下来聊聊如何备考这几门考试。针对科目2、3、4，它们的题型类似于互联网公司的笔试选择题部分。大家入职后可以在心声论坛查找相应题库进行练习。大多数同学在三次以内基本都能通过，毕竟有多年应试教育的基础，选择题相对来说还是比较容易上手的。

　　最让人头疼的，其实是**科目1**。它本质上就是华为校招机试的“业务升级版”——相比之下，题目背景更贴合实际业务。考试内容主要集中在常见的算法题，虽然考察面较窄，不会再有校招机考中出现的各种最短路算法或者数论算法，但依然包括哈希、排序、贪心、DFS、BFS，有时还会涉及动态规划等。

　　**入门级和工作级**考试相对容易应对。但**专业级考试**难度显著提升：三道题中必须完全通过两道才能合格。此外，科目一对代码质量要求更高，会限制圈复杂度（即逻辑嵌套的深度）。如果超过设定阈值，不仅会扣分，甚至可能被判为0分。通常第三题的难度也相当于 LeetCode 的 Hard 级别。

　　因此，建议大家务必提前在算法题方面下功夫，充分准备。
