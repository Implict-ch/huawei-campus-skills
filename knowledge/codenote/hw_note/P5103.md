# 面试手撕详解

> 来源：[CodeFun2000 华为校招求职笔记 · 面试手撕详解](https://codefun2000.com/codenote/hw_note/P5103)（PID `P5103`）

**Q:AI算法岗会考什么手撕？**

A:总体来讲，70%可能性考察LeetCode easy~mid的原题(90%是LeetCode Hot 100)，30%可能性考察机器学习/深度学习题

影响 你所考查的手撕的题型 的因素：

　　1.你的简历：有些面试官会根据你简历做过的项目来考察（比如看你写精通机器学习，让你撕一个kmeans / 看你有Transformer相关的项目，让你撕一个注意力机制）

　　2.面试官所擅长的领域和偏好

　　PS:塔子哥和一些华为面试官交流过，他们准备面试内容的过程没有统一的标准，各自抽时间准备。所以即使是同一个小部门，你和其他人所考察的手撕都可能是不一样的，**它和面试官强相关，随机性大**

**Q:非AI算法岗（通软/前软/数据开放等）会考什么手撕？**

A:

　　80%考察LeetCode , 20%可能性考察一些基础算法：例如手撕优先队列，手撕快速排序/归并排序等，可以多参考我的面经手撕合集。

**Q:手撕是ACM模式还是LeetCode核心代码模式？**

A:

　　根据我上一篇文章提到过的：1.线下手撕手写代码比较水，写代码是面试官肉眼检查，所以思路大差不差就行。2.线上手撕是**ACM模式**的 ,  打开IDE自行写+跑样例。这里特别推荐一下我专门为大家做的：[ACM模式速通教程](https://codefun2000.com/codenote/acm/P4504)，涵盖了求职手撕所有可能的ACM模式使用场景。

**Q:ACM模式的手撕应该用什么样的代码模板 ？**

A:

　　总体的原则是解耦+抽象+规范化命名。这个点许多面试官看的比较重。如果代码规范不好，很容易被面试官diss。这里塔子哥给出C++/Python/Java的推荐代码手撕模板

**华为的手撕可以不需要自己写输入， 可以直接将样例写死传入到函数中，如下方代码所示**

```python
class Solution:
    def solution(self, arr):
        """
        核心逻辑函数
        :param arr: 输入数组
        :return: 计算结果
        """
        return sum(arr)

if __name__ == "__main__":
    sol = Solution()

    print(sol.solution([1, 2, 3]))  # 6
    print(sol.solution([1]))        # 1
    print(sol.solution([]))         # 0

```

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    // 核心逻辑函数
    long long solution(const vector<int>& arr) {
        long long result = 0;
        for (int x : arr) {
            result += x;
        }
        return result;
    }
};

int main() {
    Solution sol;

    cout << sol.solution({1, 2, 3}) << endl; // 6
    cout << sol.solution({1}) << endl;       // 1
    cout << sol.solution({}) << endl;        // 0

    return 0;
}
```

```java
import java.util.*;

class Solution {
    // 核心逻辑函数
    public long solution(int[] arr) {
        long result = 0;
        for (int x : arr) {
            result += x;
        }
        return result;
    }
}

public class Main {
    public static void main(String[] args) {
        Solution sol = new Solution();

        System.out.println(sol.solution(new int[]{1, 2, 3})); // 6
        System.out.println(sol.solution(new int[]{1}));       // 1
        System.out.println(sol.solution(new int[]{}));        // 0
    }
}
```

**Q:撕不出来会直接挂吗？**

A:

　　这个会综合来看。如果你的bg好，项目对口，那么手撕相对会放宽一些。否则手撕一般得通过面试官所提供的所有样例+讲清楚思路才算通过。

　　第二个：一般面试官给的第一个题目你没思路，写不出来，一般面试官会给他准备的第二道题，是一道更简单的lc easy级别的题目给你撕。所以如果这都撕不出来，还是得反思一下适不适合吃程序员这碗饭。

　　此外：华为入职之后也有每年的编程考试（见第五章），所以如果真的想进入华为，建议勤加练习。
