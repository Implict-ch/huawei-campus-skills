# 题目内容

给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表

 

# 输入描述

第一行为一个整数$k$，
接下来的$k$行，每行若干个整数，以空格隔开，表示一个链表节点的值。

# 输出描述

输出共一行，包含排序后链表节点的值，用空格隔开。


## 样例1 



**输入** 

```
3
1 4 5
1 3 4
2 6
```



**输出** 

```
1 1 2 3 4 4 5 6
```

#### **说明**

[
 $1->4->5$,
 $ 1->3->4$,
 $2->6$
]
将它们合并到一个有序链表中得到。
$1->1->2->3->4->4->5->6$





#### **提示**

- $k == lists.length$
- $0 <= k <= 10^4$
- $0 <= lists[i].length <= 500$
- $-10^4 <= lists[i][j] <= 10^4$
- $lists[i]$ 按升序 排列
- $lists[i].length$ 的总和不超过 $10^4$
