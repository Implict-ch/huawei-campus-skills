# 题目描述

给定一个链表，删除链表的倒数第 `n` 个节点，并返回删除后的链表头节点。  

# 输入描述
- 第一行输入一个整数 `sz`（$1 \leq sz \leq 30$），表示链表的长度。  
- 第二行输入 `sz` 个整数（$0 \leq Node.val \leq 100$），表示链表的元素，按顺序存储。  
- 第三行输入一个整数 `n`（$1 \leq n \leq sz$），表示要删除的倒数第 `n` 个节点。  

# 输出描述
- 输出一行，表示删除后的链表，**用空格分隔**节点值。  
- 如果链表为空，则直接输出一个空行。  


### **样例输入 1**
```
5
1 2 3 4 5
2
```
### **样例输出 1**
```
1 2 3 5
```

```
1
1
1
```

```
```



### **样例输入 3**
```
2
1 2
1
```
### **样例输出 3**
