# 题目描述
给定一个 **单链表**，其节点由一个整数值表示，请判断该链表是否为 **回文链表**。  
如果是，返回 `true`；否则，返回 `false`。


# 输入格式
- 第一行输入一个整数 `n`，表示链表的 **节点数**。（`1 ≤ n ≤ 10⁵`）
- 第二行输入 `n` 个整数，表示链表的值。（`0 ≤ Node.val ≤ 9`）

# 输出格式
- 输出 `true` 或 `false`，表示链表是否为回文链表。


## 样例 1
**输入**
```
4
1 2 2 1
```
**解释**：
```
链表结构：1 → 2 → 2 → 1
```
**输出**
```
true
```

## 样例 2
**输入**
```
2
1 2
```
**解释**：
```
链表结构：1 → 2
```
**输出**
```
false
```

### 数据范围
- $ 1 \leq n \leq 10^5 $

- $ 0 \leq \text{Node.val} \leq 9 $
