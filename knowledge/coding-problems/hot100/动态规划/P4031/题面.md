[LeetCode 70. 爬楼梯](https://leetcode.cn/problems/climbing-stairs/description/)
## 题目描述

假设你正在爬楼梯。

需要 $n$ 阶你才能到达楼顶。

每次你可以爬 $1$ 个台阶或 $2$ 个台阶。

请问有多少种不同的方法可以爬到楼顶？

## 输入描述

输入一个整数 $n$，表示楼梯的台阶数。

## 输出描述

输出一个整数，表示爬到楼顶的不同方法数。

## 样例 $1$

### 输入

```
2
```

### 输出

```
2
```

### 样例解释

有 $2$ 种方法可以爬到楼顶：

$1$. $1$ 阶 $+$ $1$ 阶

$2$. $2$ 阶

## 样例 $2$

### 输入

```
3
```

### 输出

```
3
```

### 样例解释

有 $3$ 种方法可以爬到楼顶：

$1$. $1$ 阶 $+$ $1$ 阶 $+$ $1$ 阶

$2$. $1$ 阶 $+$ $2$ 阶

$3$. $2$ 阶 $+$ $1$ 阶

## 数据范围

$1 <= n <= 45$
