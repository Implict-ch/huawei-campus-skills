# 四川移动/华为/中兴/许继集团 校招 通信协议工程师面经
- 作者：帅气的大哥哥弟弟
- 来源：[四川移动/华为/中兴/许继集团 校招 通信协议工程师面经](https://www.nowcoder.com/discuss/353159208872910848)

###  四川移动成都

1. 问了有没有做过蓝牙通信；

2. 问了曾经做过哪些项目，收获，为什么做；

3. 问了以前参加过什么学校的实践活动，你从中学到了什么；

4. 问了有没有这方面的经验，你之前在哪儿工作，家人怎么想；

5. 问了对工作城市有什么要求；

###  [华为](/jump/super-jump/word?word=%E5%8D%8E%E4%B8%BA)上海研究所

1. 问了XX和[华为](/jump/super-jump/word?word=%E5%8D%8E%E4%B8%BA)给你offer你要哪个；

2. 问了你的优势有什么；

3. 问了对[华为](/jump/super-jump/word?word=%E5%8D%8E%E4%B8%BA)[思科](/jump/super-jump/word?word=%E6%80%9D%E7%A7%91)产品的了解；

4. 问了为什么选择[华为](/jump/super-jump/word?word=%E5%8D%8E%E4%B8%BA)；

5. 问了目前有拿到过哪些offer；

6. 问了怎么看待加班；

7. 问了期望工资大概是多少；

###  [中兴](/jump/super-jump/word?word=%E4%B8%AD%E5%85%B4)通讯南京研究所

1. 问了一些技术问题；

2. 问了[海量数据](/jump/super-jump/word?word=%E6%B5%B7%E9%87%8F%E6%95%B0%E6%8D%AE)通信用tcp还是udp；

3. 问了cookie和session是什么东西，有什么区别；

4. 问了一些曾经的项目，对项目中出现的光器件进行了详细的问，例如激光器的结构，各部分功能，还让画出来，以及一些常用的光器件，结构，原理；

5. 问了你认为AI+安防发展前景远大的几个领域并阐述理由；

6. 问了在大学时做过什么[算法](/jump/super-jump/word?word=%E7%AE%97%E6%B3%95)；

7. 问一些人个物质及职业规划的内容；

###  [许继集团](/jump/super-jump/word?word=%E8%AE%B8%E7%BB%A7%E9%9B%86%E5%9B%A2)

1. 问了成绩怎么样，有没有挂过科；

2. 问了许多专业的知识，比如光通信的原理，光网络的搭建之类的；

3. 用C语言问了一些基础的问题，比如阅读简单代码段，多线程的概念，进程和线程的区别，C和C++的区别等；

4. 问了想去哪个城市工作；

5. 问了对于加班的看法；
