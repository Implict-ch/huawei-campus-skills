# 华为AI软件开发一面＆二面面经
- 来源：[华为AI软件开发一面＆二面面经](https://www.xiaohongshu.com/search_result/6a07e02500000000060359cc?xsec_token=ABhkfjam9nrblwAis8epOWxiU4OsVioUhW9ubnAAXJV3Q=&xsec_source=)

注意事项：

1. 在官网下载面试的软件pc端和移动端都要下

2. 华为面试是固定时间某一天内线上排队面试，所以上一个面试者如果没结束可能有推迟耐心等待即可

3. 双机位 ————————————————— 技术面面经40min 自我介绍5min 实习＆项目5min（之前帖子有简历需要的移步） 很简单的问了下实习的内容，没有深挖 很简单的问了下项目内容，没有深挖

1. 网络四层结构是什么，分别介绍一下

2. tcp和udp详细介绍一下

3. 监督学习和无监督学习有什么区别，举几个例子

4. agent有了解吗说一下，tools,mcp,skill是什么

'('、')' 和小写字母组成的字符串 s。
需要删除最少数目的 '(' 或者 ')' ，使得剩下字符串合法。
输入：s = "hua(w(e)i)code)" 输出："hua(w(e)i)code" 输入：s = "a)b(c)d" 输出："ab(c)d" 反问5min ———————————————— 主管面面经 全程气氛很好，笑着聊天

1. 问了一下竞赛经历，你觉得竞赛中有什么收获，你和队友怎么合作的，为什么没有接着打比赛拿更高的奖项

2. 问了一下生活方面，你最近压力比较大的事情是什么，你怎么调节自己的压力

3. 问了一下实习经历，mentor给了你什么帮助，你觉得实习中好的点或者想吐槽的点，不同部门沟通的时候有矛盾怎么解决。

个人感受：很舒服的体验，面试一上午就两面面完了，主包免笔试几乎没花精力，上午主管面面完一小时就oc了，非常丝滑而且面试官感觉也聊的很好。
就是约面有点慢。
