# 中国通信/中兴南京/华为上海/中国铁通校招通信协议工程师面经
- 作者：三三.
- 来源：[中国通信/中兴南京/华为上海/中国铁通校招通信协议工程师面经](https://www.nowcoder.com/discuss/353156662812942336)

###  中国通信服务

1. 先自我介绍，说出自己成功和失败的事情；

2. 问了大学里的一些经历；

3. 问了对经常要出差的看法；

4. 问了一些常规的技术问题；

5. 问了对薪资的看法；

6. 谈一谈职业规划；

###  中兴通讯南京研究所

1. 做个自我介绍，问了家庭情况，家乡在哪；

2. 问了研究生期间做过的项目；

3. 问一些基础课程的知识，c语言，指针和数组的区别，数据库知识；

4. 用英语介绍他指定的标题的内容；

5. 问做过关于移动运营类的工作吗；

6. 问了一些对自身的评价和对公司的认识；

###  华为上海研究所

1. 就简历上提出了一些问题，成绩单对成绩做提问，最喜欢的一门课是什么；

2. 问了一些FPGA相关的基础问题，问了关于我之前做的项目情况；

3. 问了关于网优的一些问题，如何解决弱覆盖，mapinfo的，规划问题，volte的业务；

4. 你对云计算是怎么看的；

5. 对通信行业的看法，对公司的了解；

6. 问了为什么要去华为，期望的薪资是多少；

###  中国铁通

1. 自我介绍，个人的职业规划；

2. 问你对你某一专业课的理解；

3. 问了对公司和自己的看法，想要去什么岗位，对公司未来有什么看法；

4. 问了自己的专业和特长；

5. 问了我对于光信息发展近况的了解；

6. 问了之前参与过的项目，一些个人规划，以及对应聘岗位的认识及工作计划；

7. 外派到外地工作你愿意吗；
