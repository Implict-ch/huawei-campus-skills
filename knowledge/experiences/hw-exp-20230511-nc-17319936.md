# 华为2024暑期实习软件开发实习岗面经
- 作者：我要当架构师
- 来源：[华为2024暑期实习软件开发实习岗面经](https://www.nowcoder.com/discuss/486321055217319936)

背景：

双非，港中深，计算机专业

没实习，有两个跟所面岗位没什么关系的学校课程的项目

求职岗位：后端开发暑期实习，base松山湖，部门匿了

已经过了两面，等待入职中

# 一面

1. Java内存结构

2. 死锁如何处理

3. 静态内部类的特点

4. 类与类之间的关联性是如何在开发中体现的（他想问的是使用一个类存储另一个类的作为成员函数，我兜兜转转了半天，勉强算答对一半

5. Mysql是在我的项目中如何使用的

6. 我熟悉哪些软件设计原则，这些原则是在我的软件开发中是如何使用的

7. 手撕代码题：

请用Python和Java两种语言实现下题（想让我用两种语言是怕我不会写Java,因为我面试包括笔试都是Python写

请将字符串按照ASCII码的顺序进行重新排序

这道题搞的我很狼狈，我都在想要不要写个排序算法出来了，最后还是花了二十分钟套了几个娃搞出来了，面试官还安慰我别着急

对我的评价我当时感觉不太好：跟我说大学不只有做题，还应该自己动手去做一些项目（当时以为是在说我没有项目和实习经验而默拒我，已经做好被拒准备了，但是还是只过了十分钟就给我通过了

# 二面

二面之前也听说基本不刷人，所以也没太准备：

自我介绍

你觉得你有哪些优势呢，以及有哪些缺点呢，客观评价一下自己

你是哪里的考生呢？

为什么要选择现在的学校？

你觉得你选择现在的专业/工作，是出于热爱，还是未来有可能再换呢？

你在学校期间，参加过哪些竞赛呢？
取得了什么样的成绩？

你在学校内的团队中一般扮演什么样的角色呢，或者是做什么样的分工？

如果你在一个团体内，你的意见和其他人都不统一，你一般会如何做呢？

如果你在工作中遇到你处理不了的问题，你会如何处理呢？
比如有同事不知道你是新来的，给了你一个很难的工作？

你最近看的一本技术书是什么呢，有什么感悟吗？

遇到过哪些挫折，是如何度过的？

如果你在工作中遇到困难，而且ddl也比较近，你有一个问题始终无法解决，压力也比较大，你会如何克服呢

你如何看待华为的文化呢？

你觉得华为有哪些优点/缺点呢？
你如何看待这些优缺点

这些问题我觉得只要不踩雷，不搞极端基本都能过，然后我问了下面试官怎么评价我，他对我评价非常高，而且当场决定给我通过了（虽然遵守规章没有明说，但话里话外是这个意图），而且给了我很多人生和职业发展上的建议，建议完都快聊了一个小时了

实话实讲，我是有点受宠若惊的，我在一面二面之前都以为会很艰难，但其实一面二面顺利的超出想象，都是面完十分钟就给了通过的通知，尤其是在部门主管夸奖的时候一度觉得心虚，HR看到二面给过的这么快都感到不可思议

总结：

心路历程是感受到了自己学校title在技术岗面试的重要性

网上看了很多面经，一些非目标院校的面经问的问题我都看不懂的东西，都是各种高端技术，应该都是实际开发中要用的，也是我入职后要学习的东西

目标院校的问题基本都是课内知识，课内学过的东西，而且都相对比较基础，只要面试前复习复习，答的差不多我校学生基本都能过

华为的笔试也是目标院校150分通过，非目标院校350分，可见大厂对学历的严格卡位

在我对软件开发岗位基本完全无了解的情况下，依然获得了主管很高的评价，各种期许赞不绝口让我感到十分心虚(但或许都是我学校title给主管的潜意识加了buff

综上，我感觉到了自己学校title在自己求职过程中的巨大加持(至少贡献了百分之五六十吧)，很缓解了我最近一段时间找实习的焦虑，认清了自己即使对岗位的工作不熟悉，也依然有着巨大的之前未察觉到的的优势
