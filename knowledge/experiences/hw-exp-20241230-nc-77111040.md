# 我在华为的这两年——一个仅此而已的故事
- 作者：南江边
- 来源：[我在华为的这两年——一个仅此而已的故事](https://www.nowcoder.com/discuss/703298139377111040)

应邀分享一下在华为的故事，顺便赚点牛币

# 1、有点意思的面试经历

博主末流211本科菜鸡一枚，2022年春，由于考研985失败，家庭背景一般，不敢二战遂找工作。
前前后后面了不少公司（理想、海康、byd、中兴、科大讯飞等等），但是由于各种原因，如工作地点远、薪资待遇不满意等，迟迟没定下工作。
春招黄金时间快过，心灰意冷，本来只能硬着头皮回家二战了，华子突然来我们学院校招，想着最后尝试下，就和校招负责人联系了，一聊没想到负责人是老乡（过于戏剧化）。

第一关机考笔试，安排在4.27，oc了2题，300分（当时机考要求是三道编程题，选的python，第一题100、第二题200、第三题300分，过100分就能进下一面）。
ok，后面就是性格测试，没啥好说。

5.7安排时间技术面，那时候疫情全是线上面试共享桌面，对我这种I人挺友好。

面试大概是下午2点左右，面试官估计午睡刚结束，打着哈切和我说我们这岗算测试要写自动化脚本，要会代码，就现场出了道简单的字符串大小写排序题，几分钟结束，没啥好说。
后面就掏出了一套python题库（excel表格），里面基本是些选择题，记忆里有一个问assert的用法，当时学校里没用过这种测试常用函数，没答上来，以为寄了，但好像面试官挺宽容，说没事。
python题库结束后，面试官算完得分，又让我设计了一些简单的测试用例，问了些计网问题，什么tcp、sctp协议相关的知识，然后问了做了什么项目，就聊了大创、美赛，和基于神经网络识别系统毕业设计，历时1个多小时，技术面结束。
技术面结束当天就收到了通过的信息，后面就是安排主管面。
几天后的主管面就是闲聊，记忆犹新的是当时主管问我"你知道华为的企业文化是什么吗？
"我疑惑，颤颤巍巍的说了"狼性文化？
主管愣了一会儿笑了出来，然后给我介绍了正确的答案，当然我到现在也没记住他说的正确答案。
主管面也是结束当天没多久就给我发了通过短信。
当时很开心，和校招负责人（后面简称"老乡"）说了这事他也为我高兴，说offer审批流程大概两周时间，让我可以干干别的事情了。
但没想到后面才是最折磨人的一关，泡池子。

泡池子这一名词我之前都没有接触过，华子面试经历让我对此刻骨铭心。
面试通过后我就开始搞毕业设计，享受在大学最后的时光。
然而，两周后，我仍然没收到offer短信，我开始有点慌了，就给"老乡"发微信问情况。
"打扰一下，请问南京这个岗还有hc嘛？
""提交审批了，流程需要一段时间"。
一周后，又问，"还有名额吗？
"当前没有了，后面不知道会不会增加，有消息通知你"。
然后5.31~6.2又问，"老乡"不回我了。
时间来到6.7，那天我答辩刚结束，中午11左右offer短信发来了，"xxx同学，您好！
恭喜获得华为公司2022届应届生录用意向书，巴拉巴拉，感谢您的耐心等待，勇敢新世界欢迎您！
"我只能说确实感受到等待的滋味了，虽然等待过程很痛苦整天夜不能寐，但收到offer后瞬间就释怀了，很开心。

# 2、还算轻松的入职初期

毕业后，在南京从黑心二房东手上租了间房子。
7月初体检，尿酸超一点，结束后，期间玩了一圈南京。
8月初入职报到，参加了NEO培训，每天穿着红色的那个衣服真的很像印尼宽带维修人员。
这个NEO其实就是学习一下公司流程规范，入职初期的注意事项，社保、党组织转移问题答疑等，顺便夹杂着一些做团队游戏的破冰活动，NEO期间住的是安朴酒店，环境挺好就是双人间易踩雷。
NEO结束后和PL见面，参观了工位，紧接着参加了新员工FBB硬装活动，为期半个月，地点华为全球最大的云数据中心——华为云上屯。

云上屯位于贵安，园区的建筑风格和东莞的欧洲小镇类似（不知道为什么华子执着于这种风格），白天晚上开不开灯各有韵味，对于我这种没见过世面的人算是刘姥姥进大观园了。
当时第一次用慧通差旅app买机票从南京到贵州，不得不说上千的机票不用自己花钱报销的感觉真爽。
贵州硬装期间我那一批住的是花溪酒店，由于装修年代问题住宿环境不如安朴酒店，但是胜在地理位置好，在市区，出门就是集市，有公园。

硬装活动分为两部分，一部分是理论课程，另一部分是实践课程。
前一周的理论课程，主要学的是通讯中关于波分和数通的基础知识，这个没啥好说和网上课程差不多；
后一周的实践课程，就是有关波分和数通设备的实践活动，举几个还能记得的例子，比如给服务器交换机插光纤、盘光纤，制作网线和端子等，所有课程结束，组织学习考核，就是考试，考试排名前列会有奖章奖励，哈哈，这就开始卷起来了。
期间还搞了个土灶台的课程，两个小组合作完成煮米饭和做菜两个任务。
目的是让你体验下一线基站工作人员户外自己做饭的经历，自己锯柴生火、洗过切菜，最后两个小组合力做了红烧鸡肉、红烧牛肉、炒青菜、醋拌藕片四道菜。
当天风很大，柴木烧的烟灰熏得人眼睛难受，由于烹饪经验不足、烹饪条件"简陋"，做出来的菜品相一言难尽、饭菜也夹着木柴灰烬，但大伙吃起来都很香，尤其是鸡肉，最后应该没剩几块。

培训期间尝了当地的美食，牛肉粉、丝娃娃，当地的微辣要比外地吃辣一般的地区辣不少（博主被当地微辣螺蛳粉辣蒙）。
两周期间的周末，去了趟黄果树瀑布。
为了避免太像小学生写观后感，这边一笔盖过——山峰狂野壮阔，水流气势磅礴，人如沧海一粟。

# 3、逐渐厌倦的打工生活

回到现在，仔细去想入职正式工作的这两年，貌似一点感觉都没有就过去了。
南研的地理位置算华为国内所有研究所里前几名，上班通勤很方便，坐地铁出了软件大道就能打上卡。
午休氛围很好，午休时间12:00-13:30，实际可以到14:00。
每周一二四默认加班到8:30，晚上加班可以领价值25元的夜宵。
除去节假日影响月末周六固定加班，部门产品过TR月份几乎每周六加班。
华子考核也是很严格的，末尾淘汰制，每年都能看到同部门同事离职或者转部门。
干测试这段时间我的工作内容大致就是：根据新需求设计文档设计用例→评审闭环遗留问题→新增自动化脚本→做各种专项、加固。
期间还夹杂着各种环境搭建、脚本优化的杂活。
用到的知识大概就是linux命令（测试一般都需要上服务器后台操作）、python（自动化，之前还有用ruby的但逐渐淘汰了）、C/C++（这个可以帮助你看懂设计文档），不同的业务领域用到的知识肯定不同，这里仅供参考，但是个人经验来看，在华子最需要的能力是厚脸皮拉通对齐，遇到阻塞时可以很大地提升效率。
在网上也能看到其他博主所说，在华子每个底层小兵就是个螺丝钉，很难学到东西。
如果能晋升还好，但如果是待久了被优化，出去就是大难题了。

工作第一年，我和部门同批新员工一样，充满干劲，各个卷的不行，印象深刻一个女生干活干到医院住院去了。
但是一年过后，私下交流貌似加薪都少的可怜，后面大家干劲明显减少。
期间也有对领导人员管理不满，公司实行变相降薪的"人才堤坝"政策等等因素，直到现在，部门同批新员工走了一半，领导自己可能有点慌，有段时间也会私下拉会画配股大饼稳住人心。
工作内容成就感低、加薪慢、加班多、不稳定等因素，总会突然在某个时刻激起我离职的意愿，有时我会想是不是毕业继续考个研、考个公，会有更好的发展，但现实是好大学的研究生、好岗位的公务员竞争异常激烈，我能承受的起失败的风险吗？
在当前时代大背景下，普通人确实选择很少，能让你安稳过死循环的牛马日子就是最大的幸运。
在华子的这两年逐渐对大厂祛魅，想起刚上班还天天挂着红带子工牌上下班，现在想起来很好笑。
近一年时间上班对我来说仿佛憋气潜水一样，每月的发薪日就是我短暂浮出水面换气的日子，周而复始，不知道后面哪一天自己会顶不住溺水拍屁股走人。

# 4、结尾

"物竞天择，优胜劣汰"，所有活着的生命只能先接受这条规则，抓的一手烂牌也好，好牌也罢，尽自己最大努力，利用人脉资源也好，提升自身技能也好，出卖体力也好，努力获取信息差，为自己争取更多更好的选择。

不多说了祝各位躺平的能安稳躺平平平安安一辈子，有能力的大佬能早日实现阶级跨越早日暴富。
