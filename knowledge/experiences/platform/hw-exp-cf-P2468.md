# 25秋招-9月底-通用软件开发-一二三面面经

- 分类：通用软件开发

- 来源：[25秋招-9月底-通用软件开发-一二三面面经](https://codefun2000.com/ide/P2468)

1. 自我介绍

2. 简单聊了一下实习和项目，主要了解经历，无深挖

3. 介绍研究方向，做项目的时候采用的算法原理

4. 算法：字符串相关简单题

5. 简单问了几个Java和操作系统相关的八股，问题比较开放，如线程池怎么优化

# 二面 技术面 45min

1. 自我介绍

2. 重点聊了研究方向相关的项目，问了训练框架原理、采用的算法挑一个介绍原理、算法评价指标等

3. 简单聊了实习经历

4. 算法：字符串相关困难题（没思路可以换）

5. 最后也简单问了几个八股

# 三面 主管面 40min

1. 自我介绍

2. 为什么选择走通软这条路，对未来的规划是怎样的

3. 你对华为都有哪些了解，怎么看待

4. 遇到过最大的挑战是什么，你是怎样解决的

5. 拿出手机现学一个概念然后向面试官介绍，你是如何获取信息的



全程大约三小时出头，第一次线下面的感觉非常不错，面对面交流的感觉真和看着摄像头和屏幕的感觉不一样。每一位面试官都很友善、HR的安排也很及时很到位，面试场地也十分不错。
