# 26秋招-9月底-云计算AI软开-一二三面

- 分类：通用软件开发

- 来源：[26秋招-9月底-云计算AI软开-一二三面](https://codefun2000.com/ide/P2486)

### 一面 技术面 50min

1.	自我介绍。

2.	回顾笔试，逐题讲解，有些题目会扩展询问，答不上来太多会判定机考作弊。

3.	介绍项目，以及两段实习经历，做算法的思路，为什么选用这个模型？以及有没有更好的方案？

4.	简历上有C++，操作系统，计算机网络，数据库,询问C++八股（虚函数，以及右值引用），询问操作系统八股（进程间通信方式）

5.	询问关于机器学习和深度学习理解，让我把所学列出思维框架，讲解全部所学知识，相当于大纲一样，之后简单讲解类似于逻辑回归，knn，决策树，kmeans，PCA原理，以及解决什么样的问题,这个相当于是我们能说多少，他就问多少，深度学习也是一样的思维框架。

6.	算法：hot100爬楼梯改编题，爬到n阶楼梯不同方法数，以及全部路径。（记忆化回溯求解）

7.	反问环节。

### 二面 技术面40min

1.	自我介绍

2.	项目拷打，非常细节，深挖。

3.	之后询问关于深度学习八股，批归一化，层归一化的理解，以及在（b，c，w，h）哪几个维度进行计算？接着问，卷积神经网络理解，以及卷积，空洞卷积，深度可分离卷积，反卷积的理解，每种卷积的理解和如何进行操作？

4.	算法题：122.买卖股票最佳时机||（hot100原题）

5.	反问环节

### 三面 业务主管面 

1.	自我介绍

2.	关于我在实习所做的东西，有没有去业界去调研，去找我做的东西是否有其他人做过，之后展开。

3.	学习工作中遇到最困难的事情是什么，怎么解决的？之后在工作中遇到最困难事时候有没有向领导寻求帮助，最后领导给了哪些帮助？之后在工作中有没有和其他人合作经历？

4.	对华为的看法，以及是个什么样公司？

5.	我获取学习新事物的来源，举一个这样例子，平常都怎么学习新的技术。

面试过程全程非常舒服，很难得有这样畅快交流，能够很好的找出我项目中的坑，之后难得对我的项目讲的这么彻底和痛快。
