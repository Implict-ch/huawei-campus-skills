# 爱立信/佛山移动/华为/长讯通信 校招通信协议工程师面经
- 作者：空白格.
- 来源：[爱立信/佛山移动/华为/长讯通信 校招通信协议工程师面经](https://www.nowcoder.com/discuss/353159207803363328)

###  [爱立信](/jump/super-jump/word?word=%E7%88%B1%E7%AB%8B%E4%BF%A1)

1. 问了是哪里人，住在哪里；

2. 问了rip协议v1 v2版本的区别有什么；

3. 问了通信网络的基本架构，RIP是什么；

4. 问了以前从事过什么工作，为什么会选择[爱立信](/jump/super-jump/word?word=%E7%88%B1%E7%AB%8B%E4%BF%A1)；

5. 问了有什么职业规划；

6. 问了是否愿意出差；

7. 问了期待的薪资待遇；

###  佛山移动

1. 问了参加过什么社团活动；

2. 问了为什么选择佛山，为什么选择移动；

3. 问了一些与4G有关的问题；

4. 问了大学里最难忘的一件事是什么；

5. 问了觉得自己最开心的一件事是什么；

6. 问了计算机网络主要讲了什么；

###  [华为](/jump/super-jump/word?word=%E5%8D%8E%E4%B8%BA)

1. 问了一些曾经做过的项目有关的问题，比如：在项目中遇到过一些什么困难，如何克服这些困难的；

2. 问了为什么要选择我们公司；

3. 问了感觉自己适不适合这份工作，有没有信心；

4. 问了觉得这个岗位的职责是什么；

5. 问了希望有什么样的工作环境，对工作地点有什么要求吗；

6. 问了自己与其他研究生比最大的优势是什么；

###  长讯通信

1. 问了一些曾经的项目经历，比如：在项目中遇到过的难题有什么，用什么办法解决的，有过什么职责等；

2. 问了以前在什么公司工作过，为什么辞职，如果到我们这儿在不适应怎么办；

3. 问了大学时参加过什么活动，得过什么奖；

4. 问了对工作地点有什么要求，未来有什么职业规划；

5. 问了愿不愿意长期出差；

6. 问了期待的薪资待遇；
