# 复盘24号华为软开岗已进面
- 来源：[复盘24号华为软开岗已进面](https://www.xiaohongshu.com/search_result/6a43690f000000002100bf44?xsec_token=ABS1lO-lIAQDd1rmXx2lZVJOQBfJ0cm5Hseqf4Xu6-ajs=&xsec_source=)

上一场华为软开岗两题已进面，没把握的可以问，华为笔面都很熟了，简单说一下思路

第一题，给你若干电影的开始和结束时间，求最多能看多少场不重叠的电影，那么很显然这就是考虑贪心去选就好了，我们按结束时间来排序，然后维护上一场电影看完的最后时间，然后当前这个电影能选就选。

第三题，根据二叉树的前序遍历还有中序遍历还原这棵树，然后再统计每个节点到根的路径和，输出最大的K个，然后我们先递归建树，然后过程中把和给统计出来，注意就是如果 <= 0 了，那么这个子树就是不需要的了，直接 return 就好了，都存起来后输出后  K 个就行了。
