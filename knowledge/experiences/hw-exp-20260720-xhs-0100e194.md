# 华为AI岗机考真题2026-7-15第一题
- 来源：[华为AI岗机考真题2026-7-15第一题](https://www.xiaohongshu.com/search_result/6a5daa44000000000100e194?xsec_token=ABRT-HrYhstuwwWeCMgX-Kv_s4SCVZc-rDhSWPCD7zqpk=&xsec_source=)

华为AI岗机考真题2026-7-15第一题-KV Cache 稀疏化管理器 实现一个容量上限为 K 的稀疏 KV Cache，支持两种操作。
ADD 插入一个带注意力分数的 token，插入后若超容就淘汰当前分数最低的、分数并列淘汰位置编号最小的；
QUERY 按位置从小到大列出缓存里所有 token。
核心用两个结构：一个按位置有序的表负责 QUERY 顺序输出，一个最小堆按分数排、堆顶永远是该淘汰的对象。
淘汰用惰性删除：弹出堆顶后看它还在不在有序表里，在就真淘汰，不在就是早被删过的过期记录、直接跳过。
每次操作都是对数级别，总复杂度 N log N。
时间复杂度是 N log N 加输出量。
每次 ADD 入堆、每次淘汰弹堆都是 log N，每个元素最多入堆出堆各一次；
QUERY 是顺序输出。
空间复杂度是 O N，缓存和堆各最多存 N 个元素。
