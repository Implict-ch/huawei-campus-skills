# 爱立信/华为/中国移动 校招通信协议工程师面经
- 作者：互斥.
- 来源：[爱立信/华为/中国移动 校招通信协议工程师面经](https://www.nowcoder.com/discuss/353159180926263296)

###  [爱立信](/jump/super-jump/word?word=%E7%88%B1%E7%AB%8B%E4%BF%A1)

1. 问了一些个人的情况和一些简单的专业问题；

2. 问了一些学校的经历，比如：学习成绩怎么样，参加过什么活动，得过什么奖；

3. 问了这个职位有什么职责；

4. 问了为什么选择这个岗位，为什么选择[爱立信](/jump/super-jump/word?word=%E7%88%B1%E7%AB%8B%E4%BF%A1)；

5. 问了觉得自己的优点和缺点分别是什么，未来有什么职业规划；

6. 问了能否接受加班，对于出差的看法有什么；

###  [华为](/jump/super-jump/word?word=%E5%8D%8E%E4%B8%BA)

1. 问了一些专业的问题，比如：问了傅里叶变换的作用，时域与频域的区别，WCDMA与tdma区别等；

2. 问了一些在研究生期间的项目相关的问题，比如：在里面担当的职位，承担的责任有什么等；

3. 问了在学校的学习情况怎么样，对我们公司了解些什么，能不能出差；

4. 问了平时喜欢干什么，有什么特长和优点；

5. 问了最近看的一本书是什么书；

6. 问了期望的薪资待遇，对工作地点有要求吗；

###  [中国移动](/jump/super-jump/word?word=%E4%B8%AD%E5%9B%BD%E7%A7%BB%E5%8A%A8)

1. 问了一些家里的情况，方不方便出差；

2. 问了一些大学时学习情况，比如：年级排名，英语成绩怎么样，对班级有什么贡献等；

3. 问了为什么选择这个行业，为什么选择[中国移动](/jump/super-jump/word?word=%E4%B8%AD%E5%9B%BD%E7%A7%BB%E5%8A%A8)，对做好这份工作有没有信心；

4. 问了是否适应分配至各个县市；

5. 问了是否了解过光通信的相关知识及原理，自由空间隔离器的工作原理是什么；

6. 问了想要多少工资，对工作地点有什么要求；
