# 性格测评攻略

> 来源：[CodeFun2000 华为校招求职笔记 · 性格测评攻略](https://codefun2000.com/codenote/hw_note/P4511)（PID `P4511`）

# 1.**请重视华为的综合测评**

　　华为的综合测评首次通过率并不是100%，大概在7~80%。因为不少同学第一次可能只是随便做做，结果就挂掉了。而且华为的测评总共只有两次机会（实习的话，部分部门就一次补测机会，实在担心要提前和HR确认），**一旦重测也没通过，那基本就与华为无缘了**。

　　需要特别注意的是：**华为暑期实习的综合测评与秋招是共用的**。 这是一把双刃剑 —— 如果暑期实习测评通过了，秋招阶段就可以直接跳过这一环节，非常省事；但反过来说，如果你在暑期实习阶段的测评中两次未通过，那么秋招也将失去资格。

　　此外，华为技术岗基本不参与春招，因此**暑期实习和秋招是进入华为技术岗的主要机会**，务必重视这次测评。

　　**注意：评测为单机位**

# 2.测评介绍

综合测评内容：**纯性格测试**，里面不包含图形推理等行测题。

与机考的关系：与机考并无因果关系。可能在机考前收到性格测试，也可能在机考后收到测评。**机考后给你发测评 ≠ 你通过机考** 了

# 3.综合测评指南

本综合测评来自**华为HR朋友发给我的指南**。但其实大部分HR/对接人都会主动给到同学们测评注意事项，大家可以结合一起看看。

**回答导向**（从上往下优先级依次递减）

1、乐观向上且情绪稳定

2、艰苦奋斗且工作积极

3、乐于合作但不依赖同事

4、擅长数据且接受枯燥

**测评要点**

1、时间分配：尽量控制在20-30分钟内完成，不要过于纠结某道题，按照回答导向选择积极且正面的回答

2、前后回答注意保持一致

3、注意避开极端程度的用词选项（如全部、一定等）

**特殊题目类型**

1、强制选择（三个选项均为正向/负向，参考优先级优中选优）

2、前后重复（出现此题型时注意选择大致相同的选项，保持前后的一致）
