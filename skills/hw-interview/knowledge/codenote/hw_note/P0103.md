# 泡池子排序阶段

> 来源：[CodeFun2000 华为校招求职笔记 · 泡池子排序阶段](https://codefun2000.com/codenote/hw_note/P0103)（PID `P0103`）

# **面试完成到发Offer时间**

这个取决于

1.部门整体招聘流程（也就是缺人程度） 

2.部门对你的满意程度。

我们这有面完10天发Offer的(你可以看看他的[面经](https://codefun2000.com/forum/p/69dcdf13d45bb51a8ea9bf2a))，有面完一个月没泡出来的。这个没有统一结论的，因人而异，因部门而异。

# **池子排序算法**

各个部门的领导在最后拍板发Offer的时候，会拿着各位同学的各项指标：**简历，学历，面评，机考成绩,意向度**去综合看。他影响到底有多大，完全取决于领导的认知，这个没有统一结论的。

**意向度是个什么东西？**

**这里以暑期实习为例**

就是你在面试过程中，包括和 HR 沟通的时候，表现出你对这个岗位的“想来程度”和“稳定程度”，一般会从以下几个维度来看：

**1.是否接受base调配**

比如 HR 说上海 base 比较多，但你表现出更想留在北京，这种情况下意向度一般会被打低分。

**2.本科是否未来想考研/保研**

如果本科生表现出想考研/保研，或者硕士生有读博的打算，也可能会被打低分。因为暑期实习的本质是为秋招储备人才，如果你只是来实习几个月，之后还是会去考研或者去其他地方，在领导看来，一个更稳定、明确想通过秋招直接来华为就业的人，性价比会更高。

**3.实习时长**

一般来说，最好是半年，最少也要三个月。
如果过程中表现出可能会被导师叫回去，或者中间有其他安排（比如家里有事等），都会让人觉得稳定性不高，从而影响意向度。

**另外一个重要原因是**，华为的招聘流程相对比较长，不像一些公司（比如字节的日常实习），如果部门缺人、候选人合适，流程可以推进得很快。
但在华为，如果中途“鸽了”，再重新招人，整体流程会比较漫长、成本也更高，所以领导和 HR 一般不太喜欢不稳定、容易中途退出的候选人。

**ps**:有些HR表现出一种，排除万难，你只要来就给Offer的感觉。但是那是招聘初期。招聘初期他的目的是搞更多的简历，而不是拒绝更多可能的人...
