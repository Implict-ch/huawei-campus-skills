## Agent 答题指引

1. **单一考点**（「K-Means 考几次」「attention 考过什么题」）：结论含次数 → **代表真题表（具体怎么做第一步，3–4 道）** → 考法归纳 **1–2 句** → 备考建议 **1–2 句**。**禁止「频次说明」表**；共 N 道时在表下写「共 N 道，上表为代表题」，禁止第二张表或「其余 N 道」列表。
2. **概览类**（「AI 高频考点」）：Top 频次表 + Top 5 考点各 1 道代表题。
3. **选择题**：`is_choice_question: true` 无卷面，勿编造题干。
4. **未命中**：说明未收录 + [题库](https://codefun2000.com/problemset/hw) 链接。
5. **依据与边界**：代表真题表已列的题目链接**勿在依据区重复**；依据区写题库首页/备考页即可。
6. **题号**：正文（备考建议、考法归纳等）**禁止裸写 P3712**；指题用可点击标题或「上表第 N 题」。
