[Leetcode 101.对称二叉树](https://leetcode.cn/problems/symmetric-tree/description/)
## 题目描述

给定一棵二叉树的根节点 $root$，请判断这棵二叉树是否是轴对称的。

如果一棵二叉树关于根节点所在的中轴线左右对称，则称这棵二叉树是对称二叉树。

## 输入描述

输入一行若干个元素，表示二叉树的层序遍历结果。

相邻两个元素之间用一个空格隔开。

其中，整数表示节点值，$null$ 表示空节点。

## 输出描述

如果这棵二叉树是轴对称的，输出：

```
true
```

否则输出：

```
false
```

## 样例 $1$

### 输入

```
1 2 2 3 4 4 3
```

### 输出

```
true
```

![](file://oU8g6TwkCDjc-E3bNXFdr.png)

### 样例解释

该二叉树左右两侧完全对称，因此输出 $true$。

## 样例 $2$

### 输入

```
1 2 2 null 3 null 3
```

### 输出

```
false
```

![](file://z2qkk395ugTK7Eh1Odfg9.png)

### 样例解释

该二叉树左右两侧不对称，因此输出 $false$。

## 数据范围

树中节点数目范围在 $[1, 1000]$ 内。

$-100 <= Node.val <= 100$
