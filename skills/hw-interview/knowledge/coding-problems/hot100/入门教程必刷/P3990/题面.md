# 题目内容

给定一个整数数组 $nums$ ,求解数组的和。

# 输入描述

输入共两行。

- 第一行为两个个整数$n$，代表数组$nums$的长度

- 第二行为$n$个整数$nums_0,nums_1,...,nums_{n-1}$


# 输出描述

一个整数，代表数组的和

## 样例1 

**输入** 

```
4
2 7 11 15
```

**输出** 

```
35
```

## 样例2

**输入** 

```
3
3 2 4
```

**输出** 

```
9
```



## 提示 

- $2 <= nums.length <= 10^4$
- $-10^5 <= nums[i] <= 10^5$
