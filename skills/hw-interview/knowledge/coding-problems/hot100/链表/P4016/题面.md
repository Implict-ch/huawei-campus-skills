# 题目内容

给你单链表的头节点$head$ ，请你反转链表，并返回反转后的链表。

# 输入描述

输入共两行。

- 第一行为两个个整数$n$，代表单链表的长度。

- 第二行为$n$个整数，代表单链表每个节点的值，数字之间以空格分隔。第一个整数位头节点的值。

# 输出描述



## 样例1 


![image](file://Jm1RFx59Kd4ZXvid3EUiA.png) 

**输入** 

```
5
1 2 3 4 5
```

**输出** 

```
5 4 3 2 1
```

## 样例2

![image](file://UfLCAQqSAlE3W7J3zvOSy.png)

**输出**

## 提示

- 链表中节点的数目范围是 $[0, 5000]$
- $-5000 <= Node.val <= 5000$
