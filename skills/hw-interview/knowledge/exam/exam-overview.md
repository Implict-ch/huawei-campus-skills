# 华为机考制度总览 (2026)

> 政策类条目以 **`knowledge/exam/exam-format.md`** 为准。面经中的历史分值/通过线仅作背景，技巧类内容仍可参考。

## 一、是否会筛人

**会。** 机考是硬门槛，未达标一般无法进入后续面试。

## 二、考试形式与分值（2026 改革后）

> **卷种判定：** 完整岗位名称含「AI」→ AI 机考；不含 → 非 AI 机考。

### 非 AI / 开发方向（岗位名无 AI）

| 项目 | 说明 |
|------|------|
| 题量 | 3 道编程题 |
| 分值 | **150 + 150 + 300 = 600 分** |
| 通过线 | **200 分**（2026 起与 AI 岗统一，以邮件为准） |
| 模式 | **ACM**，手动处理输入输出 |
| 时长 | **2 小时**（120min，以邮件为准） |
| 语言 | C、C++、C++14、Java、Python2/3、Go、JavaScript、C#、R 等（以邮件为准） |

### AI 方向（岗位名含 AI）

| 部分 | 分值 | 通过线 |
|------|------|--------|
| 20 道选择题 | 150 | 合计 **200 分** |
| 2 道 AI 编程 | 150 + 300 | |

时长与开发岗相同：**2 小时**（120min，以邮件为准）。

## 三、评分规则

- 按**测试用例通过比例**计分（与牛客 ACM 一致）
- 多次提交取**该题最高分**
- 不会也要写：暴力/部分通过可拿分，留空为 0

## 四、监考与设备

1. **第一机位（PC）**：摄像头拍全脸 + 屏幕录制
2. **第二机位（手机）**：扫码防作弊，需拍到屏幕、键盘、上半身
3. 除考试页与本地 IDE 外，勿开社交/搜索（切屏有次数限制，超限可能作废）
4. 建议 Chrome 72+，考前调试双机位

## 五、考试时间安排（校招）

华为校招机考按渠道分场，**不是**「收到链接后 7 天内任意考完」：

| 渠道 | 常见安排 |
|------|----------|
| **国内** | **每周三晚上 19:00–21:00** |
| **留学生** | 招人有限，**不保证每周都有**；有时与国内合并同场，有时单独安排在**部分周的周四上午 9:00–11:00** |

- 实习：机考常见仅一次；挂科一般等秋招（详见笔记 FAQ）
- 秋招：默认一次；特殊情况可能全体重考，或优秀简历经 HR 申请二次（详见 [P4510](https://codefun2000.com/codenote/hw_note/P4510)）
- **免机考 / 分数沿用**：暑期机考可沿用至同卷种秋招（可再考刷分取最高）；竞赛/论文材料经 HR 审核通过可直通面试 → 见 [`exam-exempt.md`](./exam-exempt.md)
- 具体场次、是否改期、二次机会与免试结果以招聘邮件与 HR 为准

## 六、常见考点（开发岗）

| 类别 | 典型内容 |
|------|----------|
| 字符串 | 解析、过滤、滑动窗口、正则 |
| 模拟 | 状态机、队列、协议处理 |
| 搜索 | DFS、BFS |
| 排序/查找 | 双指针、二分 |
| DP | 一维/二维、区间 |
| 数据结构 | 栈、队列、哈希、树 |

AI 岗选择：机器学习、深度学习、大模型、概率论；编程多为 ML 板题。

## 七、练习资源

- **ACM 输入输出入门**：[ACM模式速通手册](https://codefun2000.com/acm/intro)
- 机考备考以塔子哥公开课 + 站内真题为主；面试手撕可用 [Hot 100](https://codefun2000.com/problemset/lchot100)

## 八、2026 校招投递（参考）

- **对象**：2026.1.1–2026.12.31 国内本硕；2025.1.1–2026.12.31 海外本硕
- **岗位**：软件开发 / AI 软件 / AI 算法 / 信息安全 / 数据开发 / 程序分析 / QEMU 嵌入式等
- **地点**：武汉 / 东莞 / 上海 等
- **面试**：国内多为线下面试，约三轮（2 技术 + 1 主管）
