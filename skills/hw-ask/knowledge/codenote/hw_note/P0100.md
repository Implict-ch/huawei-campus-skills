# 机考必备知识

> 来源：[CodeFun2000 华为校招求职笔记 · 机考必备知识](https://codefun2000.com/codenote/hw_note/P0100)（PID `P0100`）

# 一、请重视华为机考！

1.无论是秋招还是实习，机考的通过率通常在 **50%** 左右。难一些的场次通过率在 **10%~30%** 之间。

2.机考机会就一次，挂了就没戏了。**暑期实习机考挂了就只能等秋招。秋招机考挂了，只能等春招。**

那么，为什么华为的机考通过率如此低呢？有几个关键因素：

**① 机考本身难度高**

　　许多同学只刷过LeetCode Hot100，但是华为机考本身和 Hot 100 在 考察重点，考察模式和题面风格上差距大，没有真题准备的情况下去考很容易翻车。

**② 有硬性分数线**

　　华为是少数划分**硬性机考分数线**的公司。这也就是说，如果机考没有过200分的分数线，你的简历再好看，学历再牛*也于事无补。

---

### **机考成绩会不会影响后续发Offer或者秋招薪资？**

这个问题我问过不下5个华为对接人/面试官。基本可以得到结论：**机考成绩高低是会有一定影响的。但是最终他的权重有多大，完全取决于领导那边的认知**。

各个部门的领导在最后拍板发Offer的时候，会拿着各位同学的各项指标：简历，学历，面评，机考成绩等等去综合看。他影响到底有多大，完全取决于领导的认知，这个没有统一结论的。

而且这些对接人也不敢说机考成绩权重有多大，因为他们基本参与不了领导层发Offer的决策。

# 二、华为的机考考什么？

　**机考内容和报名的大部门没关系,和学历没关系，只和你的岗位名称有关系。**

　　所有**岗位名称含有"AI"字样的岗位**均考察**AI机考**，例如：AI应用工程师，AI开发工程师，AI数开工程师，AI算法工程师。

　　所有**岗位名称不含"AI"字样的岗位**均考察非AI机考，例如：通软，算法（不带AI前缀），嵌软，数据开发/分析，测试等。

​		网路安全方向：考安全方向选择题。

​		硬件方向：考硬件选择题。

​		最后两个方向塔子哥没有涉足，同学们可自行上小红书上看看经验贴。

**非AI机考介绍（200分通过）**

①考试内容：三道算法编程题，2 道 150分的题 + 1道 300分的题 ,  共600分

②考察形式：[ACM模式](https://message.bilibili.com/?spm_id_from=333.1007.0.0#/love/869398043148288)（需要自行处理输入输出） + IOI模式（见下文）

③风格特点：出题侧重业务，简单说就是更”**模拟+弯弯绕+堆需求**“。需要认真读题，尽量习惯这种题面风格。

④常见考点：DFS,BFS,排序,二分,双指针,模拟,动态规划等。

⑤来场真题：说再多不如自己先看一场[真题+解析](https://mp.weixin.qq.com/s/90AcHEKcwxWPNOEMkIKVaQ?token=1981836368&lang=zh_CN)，看看自己能做出几道！

**AI机考介绍（200分通过）**

①考试内容：20道选择题（15道单选+5道多选，共计150分） + 两道编程题(共计450分)

②考察形式：

编程题 ： ACM模式（需要自行处理输入输出） + IOI模式（见下文）

选择题：多选必须选全对，少选漏选不算分。

③风格特点：出题侧重算法场景。

④选择题常见考点：线性代数，概率论与数理统计，机器学习，深度学习，强化学习，自然语言处理，大模型

⑤编程题常见考点：Kmeans,Knn,逻辑回归，DFS,BFS,排序,二分,双指针,模拟,动态规划

⑥来场真题：说再多不如自己先看一场[真题+解析](https://mp.weixin.qq.com/s/PsdtXWKZrRT_xPhdDwmf_g)，看看自己能做出几道！

# 三、华为机考编程题得分机制：IOI赛制

AI方向和非AI方向的编程题得分机制是一样的。

提交之后会过n个测试数据（单个测试数据是一个输入对应一个输出）。假设你的代码通过$x$个测试点，那么分数就是

$$你的分数=\frac{通过的测试点}{n} * 本题分数$$

例如：300分的题目，写完代码提交之后系统反馈通过率为**30%** ，那么你的本题分数为 **30% * 300 = 90**分。

　　**注意**：在笔试的时候，你将代码提交上去之后，若不是满分会给出 错误原因以及通过率，但！它不会像力扣那样告诉你哪个自测数据有问题。**一切以通过率为准**。错误原因只是用来提醒你你的代码可能哪里有问题，他并不会影响你的通过率的分数计算。再次强调，**编程题分数只和通过率有关**，没有感情分，和你代码写的好看不好看，写的规范不规范没关系。

# 四、投完简历后多久考笔试？

笔试流程解析：笔试由考试部门统一出题，安排每周三晚7~9点统一进行考试。

你投递的部门的HR负责查看你的简历。当你的简历过筛之后，将你标记为待笔试状态。

每次机考的前3天左右，HR会询问"待笔试"的同学是否准备好了。

1.如果你说准备好了，则给你报上去。考试当周的周一，二 你的邮箱会收到华为的考试链接，点击“确认参与”按钮之后，周三晚上可点击考试链接，下载客户端进行考试。

2.如果你说你没准备好，则不给你报，继续等下一次机考。

HR每次考试前的5天左右基本都会来问你的。

所以上述过程关键卡点在：**你的简历何时过筛**。这个跟整个招聘部门进度有关，和你的学历/简历匹配度有关，没法一概而论。可以多问问HR/对接人。

结论：

最快时间：投递后的7天内安排笔试

最慢时间：投递后的1个月

平均时间：两周
