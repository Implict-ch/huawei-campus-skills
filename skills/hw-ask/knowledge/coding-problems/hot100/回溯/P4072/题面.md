# 题目内容

数字 $n$代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 有效的括号组合。



# 输入描述

一个整数$n$。

# 输出描述

输出若干行，每行一个字符串，代表一个有效的括号组合。


## 样例1 

**输入** 

```
3
```

**输出** 

```
((()))
(()())
(())()
()(())
()()()
```



## 样例2

**输入** 

```
1
```

**输出** 

```
()
```







**提示：**

- $1 <= n <= 8$
