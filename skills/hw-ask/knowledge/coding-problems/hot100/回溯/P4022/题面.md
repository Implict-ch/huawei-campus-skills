[Leetcode 78.子集](https://leetcode.cn/problems/subsets/description/)

## 题目描述

给定一个整数数组 $nums$，数组中的元素互不相同。

请返回该数组所有可能的子集。

解集不能包含重复的子集。
你可以按 任意顺序 返回解集。

## 输入描述

输入 $n$ 个整数，表示数组 $nums$ 中的元素。

## 输出描述

第一行输出一个整数 $cnt$，表示子集的数量。

接下来输出 $cnt$ 行，每行表示一个子集。

如果当前子集为空，则输出空行。

如果当前子集不为空，则输出该子集中的所有元素，相邻两个整数之间用一个空格隔开。

## 样例 $1$

### 输入

```
1 2 3
```

### 输出

```
1
2
3
1 2
1 3
2 3
1 2 3
```

## 样例 $2$

### 输入

```
0
```

### 输出

```
0
```

## 数据范围

$1 <= n <= 10$

$-10 <= nums[i] <= 10$

$nums$ 中的所有元素互不相同。
