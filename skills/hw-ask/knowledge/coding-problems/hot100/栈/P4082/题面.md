# 题目内容

给定 $n$ 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为$ 1 $。

求在该柱状图中，能够勾勒出来的矩形的最大面积。



# 输入描述
输入$n$个非负整数
# 输出描述
输出一个整数表示矩形最大面积




## 样例1 

**输入** 

```
2 1 5 6 2 3
```

**输出** 

```
10
```

![img](https://assets.leetcode.com/uploads/2021/01/04/histogram.jpg)

#### **说明**

最大的矩形为图中红色区域，面积为 $10$
