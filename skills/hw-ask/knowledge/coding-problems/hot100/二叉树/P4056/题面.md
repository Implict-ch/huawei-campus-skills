[Leetcode 543.二叉树的直径](https://leetcode.cn/problems/diameter-of-binary-tree/description/?envType=problem-list-v2&envId=2cktkvj)
## 题目描述

给定一棵二叉树的根节点 $root$，请返回该树的直径。

二叉树的直径是指树中任意两个节点之间最长路径的长度。

这条路径可能经过根节点 $root$，也可能不经过根节点 $root$。

两个节点之间路径的长度由它们之间边的数量表示。

## 输入描述

输入一行若干个元素，表示二叉树的层序遍历结果。

相邻两个元素之间用一个空格隔开。

其中，整数表示节点值，$null$ 表示空节点。

## 输出描述

输出一个整数，表示该二叉树的直径。

## 样例 $1$

### 输入

```
1 2 3 4 5
```

### 输出

```
3
```

![](file://hVmy-xWuXXfAKyt3l16gR.png)


### 样例解释

该二叉树的最长路径可以是 $[4, 2, 1, 3]$，也可以是 $[5, 2, 1, 3]$。

路径长度为 $3$，因此输出 $3$。

## 样例 $2$

### 输入

```
1 2
```

### 输出

```
1
```

## 数据范围

树中节点数目在 $[1, 10^4]$ 范围内。

$-100 <= Node.val <= 100$
