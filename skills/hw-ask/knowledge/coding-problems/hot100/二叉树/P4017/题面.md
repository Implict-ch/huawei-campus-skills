# 题目内容

给定一个二叉树的根节点$root$ ，输出它的中序遍历 。

# 输入描述

一行包含[二叉树的序列化](https://support.leetcode.cn/hc/kb/article/1567641/)数组，节点值之间用空格隔开，空节点用null表示。


# 输出描述
输出一行，从$root_0$开始中序遍历，数字之间以空格分隔。

## 样例1 

![image](file://Ztuly9iLOFUfPVpOX9m_c.png) 

**输入** 

```
1 null 2 3
```

**输出** 

```
1 3 2
```

#### 


## 样例2

**输入** 

```
1
```

**输出** 

```
1
```





## 提示

- 树中节点数目在范围 $[0, 100]$内
- $-100 <= Node.val <= 100$
