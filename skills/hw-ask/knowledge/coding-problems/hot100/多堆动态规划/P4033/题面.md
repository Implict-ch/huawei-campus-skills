[LeetCode 62. 不同路径](https://leetcode.cn/problems/unique-paths/description/)
## 题目描述

一个机器人位于一个 $m \times n$ 网格的左上角。

机器人每次只能向下或者向右移动一步。

机器人试图到达网格的右下角。

请问共有多少条不同的路径？

## 输入描述

输入两个整数 $m$ 和 $n$，分别表示网格的行数和列数。

## 输出描述

输出一个整数，表示从左上角到右下角的不同路径数量。

## 样例 $1$

### 输入

```
3 7
```

### 输出

```
28
```

## 样例 $2$

### 输入

```
3 2
```

### 输出

```
3
```

### 样例解释

从左上角开始，总共有 $3$ 条路径可以到达右下角：

$1$. 向右 $\rightarrow$ 向下 $\rightarrow$ 向下

$2$. 向下 $\rightarrow$ 向下 $\rightarrow$ 向右

$3$. 向下 $\rightarrow$ 向右 $\rightarrow$ 向下

## 样例 $3$

### 输入

```
7 3
```

### 输出

```
28
```

## 样例 $4$

### 输入

```
3 3
```

### 输出

```
6
```

## 数据范围

$1 <= m, n <= 100$

题目数据保证答案小于等于 $2 * 10^9$。
