# 题目内容

给定字符串 `s` 与字符串 `t`，请在 `s` 中找出**包含 `t` 中所有字符(含出现次数)** 的最短子串并输出该子串。
若 `s` 中不存在这样的子串，输出空字符串 `""`（不带引号）。

> 注：对 `t` 中重复字符，子串中对应字符的数量必须不少于 `t` 中该字符的数量。若存在解，保证答案唯一。

# 输入描述

* 第一行：字符串 `s`
* 第二行：字符串 `t`

# 输出描述

* 一行：最短覆盖子串；若不存在则输出空字符串 `""`。

## 样例一

输入：

```
ADOBECODEBANC
ABC
```

输出：

```
BANC
```

## 样例二

输入：

```
a
a
```

输出：

```
a
```

## 样例三

输入：

```
a
aa
```

输出：

```

```

## 数据范围

* `1 ≤ |s|, |t| ≤ 10^5`
* `s`与`t`由英文字母组成
