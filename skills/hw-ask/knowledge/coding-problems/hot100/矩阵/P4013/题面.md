[LeetCode 73.矩阵置零](https://leetcode.cn/problems/set-matrix-zeroes/description/)

## 题目描述

给定一个 $m \times n$ 的整数矩阵 $matrix$。

如果矩阵中的某个元素为 $0$，则将该元素所在行和所在列的所有元素都置为 $0$。

请使用原地算法完成操作，并输出置零后的矩阵。

## 输入描述

第一行输入两个整数 $m$ 和 $n$，分别表示矩阵的行数和列数。

接下来输入 $m$ 行，每行包含 $n$ 个整数，表示矩阵 $matrix$ 中的元素。

## 输出描述

输出 $m$ 行，每行包含 $n$ 个整数，表示置零后的矩阵。

每行中相邻两个整数之间用一个空格隔开。

## 样例 $1$

### 输入

```
3 3
1 1 1
1 0 1
1 1 1
```

### 输出

```
1 0 1
0 0 0
1 0 1
```

## 样例 $2$

### 输入

```
3 4
0 1 2 0
3 4 5 2
1 3 1 5
```

### 输出

```
0 0 0 0
0 4 5 0
0 3 1 0
```

## 数据范围

$m == matrix.length$

$n == matrix[0].length$

$1 <= m, n <= 200$

$-2^{31} <= matrix[i][j] <= 2^{31} - 1$
