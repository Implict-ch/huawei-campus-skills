[Leetcode 3.无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/)
## 题目描述

给定一个字符串 $s$，请你找出其中不含有重复字符的最长子串的长度。

子串是字符串中连续的一段字符。

## 输入描述

输入一行字符串 $s$。

字符串 $s$ 可能包含英文字母、数字、符号和空格。

## 输出描述

输出一个整数，表示字符串 $s$ 中不含重复字符的最长子串的长度。

## 样例 $1$

### 输入

```
abcabcbb
```

### 输出

```
3
```

### 样例解释

因为无重复字符的最长子串是 $abc$，所以其长度为 $3$。

注意，$bca$ 和 $cab$ 也是正确答案。

## 样例 $2$

### 输入

```
bbbbb
```

### 输出

```
1
```

### 样例解释

因为无重复字符的最长子串是 $b$，所以其长度为 $1$。

## 样例 $3$

### 输入

```
pwwkew
```

### 输出

```
3
```

### 样例解释

因为无重复字符的最长子串是 $wke$，所以其长度为 $3$。

请注意，答案必须是子串的长度，$pwke$ 是一个子序列，不是子串。

## 数据范围

$0 <= s.length <= 5 * 10^4$

$s$ 由英文字母、数字、符号和空格组成。
