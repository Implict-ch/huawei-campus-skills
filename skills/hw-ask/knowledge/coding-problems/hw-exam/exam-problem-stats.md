## Agent 答题指引

1. **编程单一考点**（「K-Means 考几次」「attention 考过什么题」）：结论含次数 → **代表真题表（3–4 道）** → 考法归纳 **1–2 句** → 备考建议 **1–2 句**。
2. **「会考 XX 吗」**（「机器学习会考吗」「华为会考线代吗」）：结论含**选择题 + 编程题**频次 → 小类分布表 → 代表真题（选择题）→ 编程标签频次 → 代表真题（编程题）→ 考法/备考。**禁止**只答一侧。
3. **选择题单一类别**（「线代选择题考几次」— 用户明确只要选择题）：结论 → 小类分布表 → 代表真题表 → 考法/备考。**禁止**输出题干选项。
4. **概览类**（「AI 选择题考哪些」「七大类分布」）：七大类频次表（**大类名即超链接**，无刷题入口列）；**禁止**逐类小类分布表。
1. **笼统备考**（「选择题怎么准备」「选择题怎么练」）：七大类频次表 + 备考建议；**禁止**小类表。
4. **未命中**：说明未收录 + [题库](https://codefun2000.com/problemset/hw) 链接。
5. **依据与边界**：代表表内链接**勿在依据区重复**；依据区写题库首页/备考页即可。
6. **题号**：正文**禁止裸写 P3712**；指场次用可点击标题或「上表第 N 场」。
