# 题面描述

实现 NTK-aware RoPE 缩放，用于长上下文外推。

标准 RoPE 在处理超过训练上下文长度的序列时，性能可能下降。NTK-aware 缩放通过调整 RoPE 的基础频率，在保留高频维度的同时拉低低频维度，从而实现无需微调的长度外推。

首先根据上下文长度比例计算新的 RoPE 基底：

`base_new = 10000 * scale^(D / (D - 2))`

然后使用新的基底，对 `q` 和 `k` 应用标准 RoPE 旋转。

## 参数说明

* `q`：查询张量，形状为 `(B, S, D)`
* `k`：键张量，形状为 `(B, S, D)`
* `scale`：上下文长度比例，即新上下文长度与训练上下文长度之比，例如长度扩展为原来的 `4` 倍时传入 `4.0`

其中：

* `B` 表示 batch 大小
* `S` 表示序列长度
* `D` 表示特征维度

## 返回值

返回旋转后的查询张量和键张量 `(q_rot, k_rot)`，两者的形状均为 `(B, S, D)`。

## 提示

* `1 <= B <= 16`
* `1 <= S <= 4096`
* `4 <= D <= 512`
* `D` 为偶数
* `1.0 <= scale <= 16.0`
* `q` 和 `k` 的形状相同
* `-10 <= q[b][s][d], k[b][s][d] <= 10`
* RoPE 的位置编号从 `0` 开始
* 使用新的 NTK 基底后，按照标准 RoPE 计算旋转频率
* 返回张量的形状和输入张量保持一致
* 你的答案与标准答案误差不超过 `1e-4` 即视为正确

## 示例 1

### 输入

```text
q = [[[1, 0, 2, 0]]]

k = [[[0, 1, 0, 2]]]

scale = 4.0
```

### 输出

```text
q_rot = [[[1, 0, 2, 0]]]

k_rot = [[[0, 1, 0, 2]]]
```

### 解释

该序列只有一个位置，其位置编号为 `0`。位置 `0` 对应的旋转角度为 `0`，因此旋转后的 `q` 和 `k` 与输入保持一致。
