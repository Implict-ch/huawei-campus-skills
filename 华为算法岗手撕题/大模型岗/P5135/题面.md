# 题面描述

实现 $CLIP$ 对比学习损失函数。

$CLIP（Contrastive Language–Image Pretraining）$通过对比学习，将图像和文本嵌入到同一向量空间。对于一个 $batch$ 中的 `N` 个图文对，$CLIP$ 损失要求匹配的图文对相似度最高。

## 参数说明

* `image_embeds`：图像嵌入矩阵，形状为 `(N, D)`，已进行 L2 归一化
* `text_embeds`：文本嵌入矩阵，形状为 `(N, D)`，已进行 L2 归一化
* `temperature`：温度参数，默认值为 `0.07`

## 返回值

返回一个标量损失值。

## 提示

* `1 <= N <= 100`
* `1 <= D <= 512`
* `-1 <= image_embeds[i][j], text_embeds[i][j] <= 1`
* `0.001 <= temperature <= 1`
* `image_embeds` 和 `text_embeds` 的形状均为 `(N, D)`
* 计算图文相似度矩阵：`logits = image_embeds @ text_embeds.T / temperature`
* 损失为图像到文本交叉熵与文本到图像交叉熵的均值
* 标签位于相似度矩阵的对角线上，即第 `i` 个图像匹配第 `i` 个文本

## 示例 1

输入

```text
image_embeds = [[1, 0],[0, 1]]

text_embeds  = [[1, 0],[0, 1]]

temperature = 1.0
```

输出

```text
0.313262
```

解释

图像嵌入与文本嵌入完全对应，匹配图文对位于相似度矩阵的对角线上。

图像到文本交叉熵和文本到图像交叉熵均为 `0.313262`，因此最终损失为 `0.313262`。
