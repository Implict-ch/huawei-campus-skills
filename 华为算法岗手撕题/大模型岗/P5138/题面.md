# 题面描述

实现 KL 散度损失。

## 参数说明

* `p_logits`：目标分布的 logits，形状为 `(B, C)`
* `q_logits`：预测分布的 logits，形状为 `(B, C)`

其中：

* `B` 表示批次大小
* `C` 表示类别数量

## 返回值

返回一个标量，表示批次平均 KL 散度。

## 提示

* `1 <= B <= 100`
* `2 <= C <= 1000`
* `-100 <= p_logits[i][j], q_logits[i][j] <= 100`
* `p_logits` 和 `q_logits` 的形状相同
* KL 散度的计算方式为：`KL(P || Q) = sum(P * log(P / Q))`
* 输入为 logits，需要先将其转换为概率分布
* 对批次中所有样本的 KL 散度取平均值

## 示例 1

### 输入

```text
p_logits = [[0, 0]]

q_logits = [[1, 0]]
```

### 输出

```text
0.120115
```

### 解释

将两组 logits 转换为概率分布后：

```text
P = [[0.500000, 0.500000]]

Q = [[0.731059, 0.268941]]
```

计算 `KL(P || Q)`，得到：

```text
0.120115
```
