# 题面描述

实现 DPO（Direct Preference Optimization，直接偏好优化）损失函数。

DPO 无需强化学习即可将语言模型与人类偏好对齐。对于每个样本，给定一对回答：一个是被偏好的回答 `chosen`，另一个是被拒绝的回答 `rejected`。

DPO 使用策略模型和参考模型在 `chosen / rejected` 上的对数概率差值，鼓励策略模型相比参考模型更加偏向 `chosen` 回答。

损失函数定义如下：

* `L = -log(sigmoid(beta * ((pi_c - ref_c) - (pi_r - ref_r)))).mean()`

其中：

* `pi_c` 表示策略模型对 `chosen` 回答的对数概率
* `pi_r` 表示策略模型对 `rejected` 回答的对数概率
* `ref_c` 表示参考模型对 `chosen` 回答的对数概率
* `ref_r` 表示参考模型对 `rejected` 回答的对数概率
* `beta` 表示温度缩放因子

请返回一个标量损失值。

你的答案与标准答案误差不超过 `1e-5` 即视为正确。

## 参数说明

* `policy_chosen_logps`：策略模型对 `chosen` 回答的对数概率，形状为 `(B,)`
* `policy_rejected_logps`：策略模型对 `rejected` 回答的对数概率，形状为 `(B,)`
* `ref_chosen_logps`：参考模型对 `chosen` 回答的对数概率，形状为 `(B,)`
* `ref_rejected_logps`：参考模型对 `rejected` 回答的对数概率，形状为 `(B,)`
* `beta`：温度缩放因子，默认值为 `0.1`

其中：

* `B` 表示 batch 大小

## 返回值

* 返回一个标量损失值

## 约束

* `1 <= B <= 100`
* `-100 <= policy_chosen_logps[i], policy_rejected_logps[i] <= 0`
* `-100 <= ref_chosen_logps[i], ref_rejected_logps[i] <= 0`
* `0.001 <= beta <= 1`
* `policy_chosen_logps、policy_rejected_logps、ref_chosen_logps、ref_rejected_logps` 的形状均为 `(B,)`
* 可以使用 `torch.nn.functional.logsigmoid` 保证数值稳定性

## 示例 1

### 输入

```text
policy_chosen_logps = [-1.0]

policy_rejected_logps = [-5.0]

ref_chosen_logps = [-2.0]

ref_rejected_logps = [-2.0]

beta = 0.5
```

### 输出

```text
0.126928
```

### 解释

策略模型中，`chosen` 相比 `rejected` 的对数概率差值为：

* `policy_chosen_logps - policy_rejected_logps = 4.0`

参考模型中，`chosen` 和 `rejected` 的对数概率差值为：

* `ref_chosen_logps - ref_rejected_logps = 0.0`

因此 DPO 中的缩放后偏好差异为：

* `0.5 * (4.0 - 0.0) = 2.0`

最终损失为：

* `-log(sigmoid(2.0)) = 0.126928`
