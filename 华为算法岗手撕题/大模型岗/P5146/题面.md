# 题面描述

实现大语言模型中常用的 SwiGLU 前馈网络模块。

SwiGLU 是一种门控前馈结构，相比普通的 ReLU FFN，它会使用一个门控分支控制另一个上投影分支的信息流动。许多大模型的 FFN 层都全采用类似结构。

给定输入张量 `x`，以及三组权重矩阵 `W_gate`、`W_up`、`W_down`，请你计算 SwiGLU FFN 的输出。

计算过程如下：

1. 门控分支：

   * `gate = x · W_gate`

2. 上投影分支：

   * `up = x · W_up`

3. SwiGLU 激活：

   * `hidden = silu(gate) * up`

4. 其中：

   * `silu(t) = t * sigmoid(t)`
   * `sigmoid(t) = 1 / (1 + exp(-t))`

5. 下投影输出：

   * `out = hidden · W_down`

请返回输出张量 `out`，形状为 `B × S × D`。

你的答案与标准答案误差不超过 `1e-5` 即视为正确。

## 参数说明

* `x`：输入张量，形状为 `B × S × D`
* `W_gate`：门控分支权重矩阵，形状为 `D × H`
* `W_up`：上投影分支权重矩阵，形状为 `D × H`
* `W_down`：下投影权重矩阵，形状为 `H × D`

其中：

* `B` 表示 batch 大小
* `S` 表示序列长度
* `D` 表示模型隐藏维度
* `H` 表示 FFN 中间层维度

## 返回值

* 返回 SwiGLU FFN 的输出张量，形状为 `B × S × D`

## 约束

* `1 <= B <= 16`
* `1 <= S <= 128`
* `1 <= D <= 512`
* `1 <= H <= 2048`
* `-10 <= x[b][s][d] <= 10`
* `-10 <= W_gate[i][j], W_up[i][j], W_down[i][j] <= 10`
* `W_gate` 和 `W_up` 的形状均为 `D × H`
* `W_down` 的形状为 `H × D`
* `silu(t)` 需要按照 `t * sigmoid(t)` 计算
* `hidden = silu(gate) * up` 中的乘法为逐元素相乘
* 不需要添加 bias
* 可以使用基础矩阵乘法和逐元素运算实现

## 示例 1

### 输入

```text
x = [[[1.0, 0.0],
      [0.0, 1.0]]]

W_gate = [[1.0, 0.0],
          [0.0, 1.0]]

W_up = [[2.0, 0.0],
        [0.0, 2.0]]

W_down = [[1.0, 0.0],
          [0.0, 1.0]]
```

### 输出

```text
out = [[[1.462117, 0.000000],
        [0.000000, 1.462117]]]
```

### 解释

对于第一个 token：

* `gate = [1.0, 0.0]`
* `up = [2.0, 0.0]`

计算 SiLU：

* `silu(1.0) = 1.0 * sigmoid(1.0) = 0.731058`
* `silu(0.0) = 0.0`

因此：

* `hidden = [0.731058, 0.0] * [2.0, 0.0] = [1.462117, 0.0]`

由于 `W_down` 是单位矩阵，所以输出保持为：

* `[1.462117, 0.0]`

第二个 token 同理，最终得到输出矩阵。
