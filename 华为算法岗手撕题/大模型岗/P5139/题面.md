# 题面描述

实现分页注意力（Paged Attention，vLLM 风格）。

KV 缓存不再连续存储，而是存放在固定大小的页（block）中。`block_table` 将逻辑块索引映射到物理页索引，从而实现非连续的内存分配。

首先根据 `block_table` 收集每条序列对应的 K/V 页，将其拼接并截取到 `context_len`，然后执行标准缩放点积注意力计算。

## 参数说明

* `q`：查询张量，形状为 `(B, 1, D)`
* `k_pages`：键缓存页，形状为 `(num_pages, block_size, D)`
* `v_pages`：值缓存页，形状为 `(num_pages, block_size, D)`
* `block_table`：整数张量，形状为 `(B, max_blocks)`，用于将逻辑块索引映射到物理页索引
* `context_len`：每条序列中有效 KV token 的数量
* `block_size`：每个缓存页包含的 token 数量

其中：

* `B` 表示批次大小
* `D` 表示特征维度
* `num_pages` 表示物理页总数
* `max_blocks` 表示每条序列最多使用的逻辑块数量

## 返回值

返回分页注意力的输出张量，形状为 `(B, 1, D)`。

## 提示

* `1 <= B <= 16`
* `1 <= D <= 256`
* `1 <= block_size <= 64`
* `1 <= context_len <= 4096`
* `1 <= num_pages <= 4096`
* `1 <= max_blocks <= 4096`
* `-10 <= q[b][0][d] <= 10`
* `-10 <= k_pages[p][i][d], v_pages[p][i][d] <= 10`
* `k_pages` 和 `v_pages` 的形状相同
* `0 <= block_table[b][i] < num_pages`
* `max_blocks × block_size >= context_len`
* 按照 `block_table` 中的顺序收集 K/V 页
* 拼接缓存页后，只保留前 `context_len` 个 token
* 使用缩放因子 `sqrt(D)` 计算标准缩放点积注意力
* 你的答案与标准答案误差不超过 `1e-4` 即视为正确

## 示例 1

### 输入

```text
q = [[[1, 0]]]

k_pages = [[[1, 1],
            [0, 0]],

           [[1, 0],
            [0, 1]]]

v_pages = [[[1, 1],
            [0, 0]],

           [[1, 0],
            [0, 1]]]

block_table = [[1, 0]]

context_len = 3

block_size = 2
```

### 输出

```text
[[[0.8022, 0.5989]]]
```

### 解释

根据 `block_table = [[1, 0]]`，先读取物理页 `1`，再读取物理页 `0`。拼接并截取前 `3` 个 token 后得到：

```text
K = [[1, 0],
     [0, 1],
     [1, 1]]

V = [[1, 0],
     [0, 1],
     [1, 1]]
```

使用 `q` 对上述 K/V 执行缩放点积注意力，最终得到输出 `[[[0.8022, 0.5989]]]`。
