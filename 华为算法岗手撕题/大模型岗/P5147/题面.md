# 题面描述

实现 $GRPO（Group Relative Policy Optimization，组相对策略优化）$损失函数。

$GRPO$ 是大模型强化学习对齐中常用的优化方法。与 $PPO$ 需要为每个值模型估计 $advantage$ 不同，$GRPO$ 会对同一个 $prompt$ 采样多个回答，并使用每组回答的 $reward$ 相对关系来计算 $advantage$。

给定当前策略模型的对数概率 `policy_logps`、旧策略模型的对数概率 `old_logps`、参考模型的对数概率 `ref_logps`，以及每组回答的奖励 `rewards`，请你计算 $GRPO$ 损失。

对于每个 $prompt$ 下的 `G` 个回答，先计算组内归一化 $advantage$：

* `mean_reward = mean(rewards, dim=1)`
* `std_reward = sqrt(mean((rewards - mean_reward)^2, dim=1) + adv_eps)`
* `advantages = (rewards - mean_reward) / std_reward`

然后计算策略比值：

* `ratio = exp(policy_logps - old_logps)`

使用 $PPO$ 风格的 $clip$ 目标：

* `surr1 = ratio * advantages`
* `surr2 = clamp(ratio, 1 - clip_eps, 1 + clip_eps) * advantages`
* `policy_loss = -mean(min(surr1, surr2))`

同时加入参考模型 $KL$ 惩罚项：

* `kl = mean(exp(ref_logps - policy_logps) - (ref_logps - policy_logps) - 1)`

最终 $GRPO$ 损失为：

* `loss = policy_loss + beta * kl`

请返回一个标量损失值。

你的答案与标准答案误差不超过 `1e-5` 即视为正确。

## 参数说明

* `policy_logps`：当前策略模型对每个回答的对数概率，形状为 `B × G`
* `old_logps`：旧策略模型对每个回答的对数概率，形状为 `B × G`
* `ref_logps`：参考模型对每个回答的对数概率，形状为 `B × G`
* `rewards`：每个回答对应的奖励，形状为 `B × G`
* `clip_eps`：$clip$ 截断范围，默认值为 `0.2`
* `beta`：KL 惩罚系数，默认值为 `0.1`
* `adv_eps`：$advantage$ 归一化的数值稳定项，默认值为 `1e-8`

其中：

* `B` 表示 $prompt$ 的数量
* `G` 表示每个 $prompt$ 采样的回答数量

## 返回值

* 返回一个标量损失值，表示 $GRPO loss$

## 约束

* `1 <= B <= 32`
* `2 <= G <= 16`
* `-100 <= policy_logps[b][g], old_logps[b][g], ref_logps[b][g] <= 0`
* `-100 <= rewards[b][g] <= 100`
* `0 <= clip_eps <= 1`
* `0 <= beta <= 1`
* `0 <= adv_eps <= 1e-6`
* `policy_logps`、`old_logps`、`ref_logps`、`rewards` 的形状均为 `B × G`
* 每个 prompt 对应的一组 rewards 中，至少存在两个不同的 reward
* advantage 需要在每个组内部单独归一化
* `clamp(ratio, 1 - clip_eps, 1 + clip_eps)` 表示将 `ratio` 限制在 `[1 - clip_eps, 1 + clip_eps]` 范围内
* `min(surr1, surr2)` 为逐元素取最小值
* 最终对所有 `B × G` 个元素取平均
* 可以使用基础张量运算实现

## 示例 1

### 输入

```text
policy_logps = [[-0.8, -2.2]]

old_logps = [[-1.0, -2.0]]

ref_logps = [[-1.0, -2.0]]

rewards = [[3.0, 1.0]]

clip_eps = 0.2

beta = 0.1
```

### 输出

```text
-0.188628
```

### 解释

该输入中只有 `1` 个 $prompt$，每个 $prompt$ 有 `2` 个回答。

首先计算组内 $reward$ 的均值和标准差：

* `mean_reward = 2.0`
* `std_reward = 1.0`

因此：

* `advantages = [1.0, -1.0]`

计算策略比值：

* `ratio = exp(policy_logps - old_logps) = [1.2214, 0.8187]`

$clip$ 后得到：

* `clipped_ratio = [1.2, 0.8187]`

计算两个 $surrogate$ 项：

* `surr1 = [1.2214, -0.8187]`
* `surr2 = [1.2, -0.8187]`

逐元素取最小值：

* `min(surr1, surr2) = [1.2, -0.8187]`

因此：

* `policy_loss = -mean([1.2, -0.8187]) = -0.190635`

KL 惩罚项为：

* `kl = 0.020067`

最终损失为：

* `loss = -0.190635 + 0.1 * 0.020067 = -0.188628`
