# 题面描述

实现 **FM（Factorization Machine，因子分解机）** 的前向预测。

FM 常用于推荐、广告点击率预估等任务。它可以建模特征之间的二阶交叉关系，并通过隐向量内积的方式减少参数数量。

给定样本特征矩阵 `X`、一阶权重 `w`、全局偏置 `w0` 和特征隐向量矩阵 `V`，请你计算每个样本的 FM 预测值。

FM 的预测公式如下：

* `y_hat = w0 + sum(w_i * x_i) + sum(<v_i, v_j> * x_i * x_j)`

其中：

* 第一项 `w0` 是全局偏置
* 第二项是线性部分
* 第三项是所有不同特征两两之间的二阶交叉项
* `<v_i, v_j>` 表示第 `i` 个特征和第 `j` 个特征隐向量的内积

也可以使用等价的高效计算公式：

* `interaction = 0.5 * sum((X · V)^2 - (X^2 · V^2))`

请返回所有样本的预测值。

你的答案与标准答案误差不超过 `1e-6` 即视为正确。

## 参数说明

* `X`：样本特征矩阵，形状为 `N × D`
* `w`：一阶权重向量，长度为 `D`
* `w0`：全局偏置，标量
* `V`：特征隐向量矩阵，形状为 `D × K`

其中：

* `N` 表示样本数量
* `D` 表示特征数量
* `K` 表示每个特征对应的隐向量维度

## 返回值

返回预测值向量 `y_hat`，长度为 `N`

## 约束

* `1 <= N <= 200`
* `1 <= D <= 100`
* `1 <= K <= 50`
* `-100 <= X[i][j] <= 100`
* `-100 <= w[i] <= 100`
* `-100 <= w0 <= 100`
* `-100 <= V[i][k] <= 100`
* 二阶交叉项只计算 `i < j` 的特征对
* 不需要对输出做 `sigmoid`
* 可以直接枚举二阶特征交叉，也可以使用高效公式计算
* 不能使用现成的 FM 模型库

## 示例 1

### 输入

```text
X = [[1.0, 0.0, 1.0],
     [0.0, 1.0, 1.0]]

w = [1.0, -1.0, 0.5]

w0 = 0.5

V = [[1.0, 0.0],
     [0.0, 1.0],
     [1.0, 1.0]]
```

### 输出

```text
y_hat = [3.000000, 1.000000]
```

### 解释

对于第一个样本 `[1.0, 0.0, 1.0]`：

线性部分为：

* `1.0 * 1.0 + (-1.0) * 0.0 + 0.5 * 1.0 = 1.5`

二阶交叉项，只有第 `0` 个特征和第 `2` 个特征同时非零：

* `<V[0], V[2]> * 1.0 * 1.0 = 1.0`

因此预测值为：

* `0.5 + 1.5 + 1.0 = 3.0`

对于第二个样本 `[0.0, 1.0, 1.0]`：

线性部分为：

* `-1.0 + 0.5 = -0.5`

二阶交叉项为：

* `<V[1], V[2]> * 1.0 * 1.0 = 1.0`

因此预测值为：

* `0.5 - 0.5 + 1.0 = 1.0`
