# 题面描述

给定一个回归任务的数据集 `X`、真实标签 `y` 和当前模型预测值 `pred`，请你实现 **GBDT（Gradient Boosting Decision Tree）** 的一轮拟合。

本题使用平方损失：

* `loss = 1/2 * (y - pred)^2`

在平方损失下，负梯度等于残差：

* `residual = y - pred`

本轮需要拟合一棵深度为 `1` 的回归树，也就是一个决策树桩。对于每个特征，枚举所有候选划分值 `threshold`，将样本划分为左右两个子集：

* 左叶子：`X[i][feature] <= threshold`
* 右叶子：`X[i][feature] > threshold`

每个叶子节点的预测值为该叶子内所有残差的平均值：

* `left_value = mean(residuals in left)`
* `right_value = mean(residuals in right)`

划分误差定义为左右叶子残差平方误差之和：

* `sse = sum((residual - leaf_value)^2)`

请选择 `sse` 最小的划分，并用该树更新预测值：

* `pred_new[i] = pred[i] + learning_rate * leaf_value`

请返回：

* `best_feature`
* `best_threshold`
* `left_value`
* `right_value`
* `pred_new`

你的答案与标准答案误差不超过 `1e-6` 即视为正确。

## 参数说明

* `X`：样本特征矩阵，形状为 `N × M`
* `y`：真实标签，形状为 `(N,)`
* `pred`：当前模型预测值，形状为 `(N,)`
* `learning_rate`：学习率

其中：

* `N` 表示样本数量
* `M` 表示特征数量

## 返回值

返回一轮 GBDT 拟合后的结果 `(best_feature, best_threshold, left_value, right_value, pred_new)`

其中：

* `best_feature` 表示本轮树选择的特征下标
* `best_threshold` 表示本轮树选择的划分阈值
* `left_value` 表示左叶子的预测值
* `right_value` 表示右叶子的预测值
* `pred_new` 表示更新后的预测值，形状为 `(N,)`

## 约束

* `2 <= N <= 200`
* `1 <= M <= 20`
* `-100 <= X[i][j] <= 100`
* `-100 <= y[i] <= 100`
* `-100 <= pred[i] <= 100`
* `0 < learning_rate <= 1`
* 每个特征的候选阈值为相邻不同特征值的中点
* 如果某个特征的所有取值都相同，则该特征不产生候选划分
* 保证至少存在一个合法划分
* 如果多个划分的 `sse` 相同，选择 `best_feature` 更小的划分
* 如果 `best_feature` 也相同，选择 `best_threshold` 更小的划分
* 不能使用 `sklearn`、`xgboost`、`lightgbm` 等机器学习库

## 示例 1

### 输入

```text
X = [[1.0],
     [2.0],
     [3.0],
     [4.0]]

y = [2.0, 2.0, 4.0, 4.0]

pred = [3.0, 3.0, 3.0, 3.0]

learning_rate = 0.5
```

### 输出

```text
best_feature = 0

best_threshold = 2.5

left_value = -1.0

right_value = 1.0

pred_new = [2.5, 2.5, 3.5, 3.5]
```

### 解释

首先计算残差：

* `residual = y - pred = [-1.0, -1.0, 1.0, 1.0]`

当选择第 `0` 个特征，阈值为 `2.5` 时：

* 左叶子包含前两个样本，残差为 `[-1.0, -1.0]`
* 右叶子包含后两个样本，残差为 `[1.0, 1.0]`

因此：

* `left_value = -1.0`
* `right_value = 1.0`

左右叶子的残差平方误差均为 `0`，因此该划分最优。

使用学习率 `0.5` 更新预测值：

* 左叶子样本：`3.0 + 0.5 * (-1.0) = 2.5`
* 右叶子样本：`3.0 + 0.5 * 1.0 = 3.5`

最终得到：

* `pred_new = [2.5, 2.5, 3.5, 3.5]`
