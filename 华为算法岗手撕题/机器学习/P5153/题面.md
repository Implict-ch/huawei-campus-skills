# 题面描述

给定一个二分类数据集 `X` 和标签 `y`，请你实现决策树中基于 **Gini 指数下降量** 的最佳划分选择。

对于每个特征，需要枚举所有可能的划分阈值 `threshold`，将样本划分为左右两个子集：

* 左子集：`X[i][feature] <= threshold`
* 右子集：`X[i][feature] > threshold`

Gini 指数定义如下：

* `Gini(D) = 1 - p0^2 - p1^2`

其中：

* `p0` 表示数据集中标签为 `0` 的样本比例
* `p1` 表示数据集中标签为 `1` 的样本比例

一次划分后的加权 Gini 指数为：

* `Gini_split = len(left) / N * Gini(left) + len(right) / N * Gini(right)`

Gini 增益定义为：

* `gain = Gini(parent) - Gini_split`

请返回 Gini 增益最大的划分：

* `best_feature`
* `best_threshold`
* `best_gain`

你的答案与标准答案误差不超过 `1e-6` 即视为正确。

## 参数说明

* `X`：样本特征矩阵，形状为 `N × M`
* `y`：样本标签，形状为 `(N,)`，每个标签为 `0` 或 `1`

其中：

* `N` 表示样本数量
* `M` 表示特征数量

## 返回值

* 返回最佳划分结果 `(best_feature, best_threshold, best_gain)`

其中：

* `best_feature` 表示最佳划分使用的特征下标
* `best_threshold` 表示最佳划分阈值
* `best_gain` 表示该划分对应的 Gini 增益

## 约束

* `2 <= N <= 200`
* `1 <= M <= 20`
* `-100 <= X[i][j] <= 100`
* `y[i]` 只能为 `0` 或 `1`
* 每个特征的候选阈值为相邻不同特征值的中点
* 如果某个特征的所有取值都相同，则该特征不产生候选划分
* 保证至少存在一个合法划分
* 如果多个划分的 `best_gain` 相同，选择 `best_feature` 更小的划分
* 如果 `best_feature` 也相同，选择 `best_threshold` 更小的划分

## 示例 1

### 输入

```text
X = [[1.0, 2.0],
     [2.0, 1.0],
     [3.0, 2.0],
     [4.0, 3.0]]

y = [0, 0, 1, 1]
```

### 输出

```text
best_feature = 0

best_threshold = 2.5

best_gain = 0.500000
```

### 解释

父节点中标签为 `0` 和 `1` 的样本各有 `2` 个，因此：

* `Gini(parent) = 1 - 0.5^2 - 0.5^2 = 0.5`

当选择第 `0` 个特征，阈值为 `2.5` 时：

* 左子集包含样本 `[1.0, 2.0]`，标签为 `[0, 0]`
* 右子集包含样本 `[3.0, 4.0]`，标签为 `[1, 1]`

左右子集纯度均达到：

* `Gini(left) = 0`
* `Gini(right) = 0`

因此：

* `Gini_split = 0`
* `gain = 0.5 - 0 = 0.5`

该划分的 Gini 增益最大，因此返回：

* `(0, 2.5, 0.500000)`
