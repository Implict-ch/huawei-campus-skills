# 题面描述

给定一个样本特征矩阵 `X` 和目标降维维度 `k`，请你实现 **PCA（Principal Component Analysis，主成分分析）** 降维。

PCA 的目标是找到方差最大的若干个正交方向，并将原始数据投影到这些方向上，从而得到低维表示。

计算过程如下：

1. 对数据按特征维度求均值：

   * `mean[j] =` 所有样本第 `j` 个特征的平均值

2. 对原始数据进行中心化：

   * `X_centered = X - mean`

3. 计算协方差矩阵：

   * `cov = X_centered^T · X_centered / N`

4. 对协方差矩阵进行特征值分解，选取最大的 `k` 个特征值对应的特征向量作为主成分。

5. 将中心化后的数据投影到主成分上：

   * `Z = X_centered · components`

请返回降维后的矩阵 `Z`，形状为 `N × k`。

你的答案与标准答案误差不超过 `1e-5` 即视为正确。

## 参数说明

* `X`：样本特征矩阵，形状为 `N × D`
* `k`：目标降维维度

其中：

* `N` 表示样本数量
* `D` 表示原始特征维度

## 返回值

返回降维后的矩阵 `Z`，形状为 `N × k`

## 约束

* `2 <= N <= 200`
* `1 <= D <= 50`
* `1 <= k <= D`
* `-100 <= X[i][j] <= 100`
* 协方差矩阵使用 `X_centered^T · X_centered / N` 计算
* 主成分按照特征值从大到小排序
* 如果特征向量整体符号不唯一，规定每个特征向量中第一个非零元素必须为正
* 如果多个特征值相同，按照特征向量调整符号后的字典序从小到大排序
* 返回结果必须由中心化后的数据投影得到
* 不能使用 `sklearn` 等机器学习库
* 可以使用基础线性代数库中的特征值分解函数

## 示例 1

### 输入

```text
X = [[1.0, 0.0],
     [2.0, 0.0],
     [3.0, 0.0],
     [4.0, 0.0]]

k = 1
```

### 输出

```text
Z = [[-1.500000],
     [-0.500000],
     [ 0.500000],
     [ 1.500000]]
```

### 解释

每个特征的均值为：

* `mean = [2.5, 0.0]`

中心化后：

* `X_centered = [[-1.5, 0.0], [-0.5, 0.0], [0.5, 0.0], [1.5, 0.0]]`

数据的最大方差方向为第 `0` 个特征方向：

* `component = [1.0, 0.0]`

将中心化后的数据投影到该主成分上，得到：

* `Z = [[-1.5], [-0.5], [0.5], [1.5]]`
