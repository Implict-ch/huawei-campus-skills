# 题面描述

给定样本特征矩阵 `X`，以及每个样本的一阶梯度 `g` 和二阶梯度 `h`，请你实现 XGBoost 中基于 **Split Gain** 的最佳划分选择。

对于每个特征，需要枚举所有可能的划分阈值 `threshold`，将样本划分为左右两个子集：

* 左子集：`X[i][feature] <= threshold`
* 右子集：`X[i][feature] > threshold`

设某个节点中所有样本的一阶梯度和为 `G`，二阶梯度和为 `H`，则该节点的分数为：

* `Score = G^2 / (H + reg_lambda)`

一次划分的增益定义为：

* `gain = 0.5 * (Score_left + Score_right - Score_parent) - gamma`

其中：

* `Score_left = G_left^2 / (H_left + reg_lambda)`
* `Score_right = G_right^2 / (H_right + reg_lambda)`
* `Score_parent = G_parent^2 / (H_parent + reg_lambda)`

请返回 Split Gain 最大的划分：

* `best_feature`
* `best_threshold`
* `best_gain`

你的答案与标准答案误差不超过 `1e-6` 即视为正确。

## 参数说明

* `X`：样本特征矩阵，形状为 `N × M`
* `g`：每个样本的一阶梯度，形状为 `(N,)`
* `h`：每个样本的二阶梯度，形状为 `(N,)`
* `reg_lambda`：L2 正则项系数
* `gamma`：分裂惩罚项

其中：

* `N` 表示样本数量
* `M` 表示特征数量

## 返回值

* 返回最佳划分结果 `(best_feature, best_threshold, best_gain)`

其中：

* `best_feature` 表示最佳划分使用的特征下标
* `best_threshold` 表示最佳划分阈值
* `best_gain` 表示该划分对应的 Split Gain

## 约束

* `2 <= N <= 200`
* `1 <= M <= 20`
* `-100 <= X[i][j] <= 100`
* `-100 <= g[i] <= 100`
* `1e-6 <= h[i] <= 100`
* `0 <= reg_lambda <= 100`
* `0 <= gamma <= 100`
* 每个特征的候选阈值为相邻不同特征值的中点
* 如果某个特征的所有取值都相同，则该特征不产生候选划分
* 保证至少存在一个合法划分
* 如果多个划分的 `best_gain` 相同，选择 `best_feature` 更小的划分
* 如果 `best_feature` 也相同，选择 `best_threshold` 更小的划分
* 不能使用 `xgboost`、`sklearn` 等机器学习库

## 示例 1

### 输入

```text
X = [[1.0],
     [2.0],
     [3.0],
     [4.0]]

g = [-2.0, -1.0, 1.0, 2.0]

h = [1.0, 1.0, 1.0, 1.0]

reg_lambda = 1.0

gamma = 0.0
```

### 输出

```text
best_feature = 0

best_threshold = 2.5

best_gain = 3.000000
```

### 解释

父节点中：

* `G_parent = -2.0 + (-1.0) + 1.0 + 2.0 = 0.0`
* `H_parent = 4.0`
* `Score_parent = 0.0`

对于第 `0` 个特征，候选阈值包括：

* `1.5`
* `2.5`
* `3.5`

当阈值为 `2.5` 时：

* 左子集包含前两个样本，`G_left = -3.0`，`H_left = 2.0`
* 右子集包含后两个样本，`G_right = 3.0`，`H_right = 2.0`

因此：

* `Score_left = (-3.0)^2 / (2.0 + 1.0) = 3.0`
* `Score_right = 3.0^2 / (2.0 + 1.0) = 3.0`

最终增益为：

* `gain = 0.5 * (3.0 + 3.0 - 0.0) - 0.0 = 3.000000`

该划分的 Split Gain 最大，因此返回：

* `(0, 2.5, 3.000000)`
