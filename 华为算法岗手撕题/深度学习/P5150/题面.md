# 题面描述

实现 LayerNorm（Layer Normalization）的前向计算。

LayerNorm 是深度学习模型中常用的归一化方法。与 BatchNorm 不同，LayerNorm 对每个样本的最后一个维度独立计算均值和方差，然后进行归一化，并使用可学习参数 `weight` 和 `bias` 进行缩放和平移。

给定输入张量 `x`、缩放参数 `weight` 和偏置参数 `bias`，请你计算 LayerNorm 的输出。

对于每个位置上的特征向量 `x_i`，LayerNorm 定义如下：

* `mean = mean(x_i)`
* `var = mean((x_i - mean)^2)`
* `y_i = (x_i - mean) / sqrt(var + eps) * weight + bias`

其中 `mean` 和 `var` 都是在最后一个维度 `D` 上计算。

请返回归一化后的张量 `y`，形状与输入 `x` 相同。

你的答案与标准答案误差不超过 `1e-5` 即视为正确。

## 参数说明

* `x`：输入张量，形状为 `B × S × D`
* `weight`：缩放参数，形状为 `(D,)`
* `bias`：偏置参数，形状为 `(D,)`
* `eps`：数值稳定项，默认值为 `1e-5`

其中：

* `B` 表示 batch 大小
* `S` 表示序列长度
* `D` 表示隐藏层特征维度

## 返回值

* 返回 LayerNorm 后的张量，形状为 `B × S × D`

## 约束

* `1 <= B <= 16`
* `1 <= S <= 128`
* `2 <= D <= 512`
* `-10 <= x[b][s][d] <= 10`
* `-10 <= weight[d] <= 10`
* `-10 <= bias[d] <= 10`
* `0 <= eps <= 1e-3`
* LayerNorm 只在最后一个维度 `D` 上计算均值和方差
* 方差计算使用总体方差，即除以 `D`
* 输出形状必须与输入 `x` 保持一致
* 不能直接使用 `torch.nn.LayerNorm`
* 可以使用基础张量运算实现
* 如果 `eps = 0`，保证每个位置上的方差大于 `0`

## 示例 1

### 输入

```text
x = [[[1.0, 2.0, 3.0],
      [2.0, 4.0, 6.0]]]

weight = [1.0, 1.0, 1.0]

bias = [0.0, 0.0, 0.0]

eps = 0.0
```

### 输出

```text
y = [[[-1.224745, 0.000000, 1.224745],
      [-1.224745, 0.000000, 1.224745]]]
```

### 解释

对于第一个 token：

* `x = [1.0, 2.0, 3.0]`
* `mean = 2.0`
* `var = ((1 - 2)^2 + (2 - 2)^2 + (3 - 2)^2) / 3 = 0.666667`

归一化后得到：

* `[-1.224745, 0.000000, 1.224745]`

对于第二个 token：

* `x = [2.0, 4.0, 6.0]`
* `mean = 4.0`
* `var = ((2 - 4)^2 + (4 - 4)^2 + (6 - 4)^2) / 3 = 2.666667`

归一化后同样得到：

* `[-1.224745, 0.000000, 1.224745]`

由于 `weight` 全为 `1.0`，`bias` 全为 `0.0`，最终输出保持为归一化结果。
