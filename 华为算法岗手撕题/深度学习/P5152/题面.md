# 题面描述

实现 AdamW 优化器的一步参数更新。

给定当前参数 `params`、梯度 `grads`、一阶动量 `m` 和二阶动量 `v`，请你根据 AdamW 的更新规则，计算更新后的参数 `params_new`。

本题中固定使用以下超参数：

* `lr = 0.01`
* `beta1 = 0.9`
* `beta2 = 0.999`
* `eps = 1e-8`
* `weight_decay = 0.1`
* `t = 1`

AdamW 的动量更新公式如下：

* `m_new = beta1 * m + (1 - beta1) * grads`
* `v_new = beta2 * v + (1 - beta2) * grads^2`

偏置修正如下：

* `m_hat = m_new / (1 - beta1^t)`
* `v_hat = v_new / (1 - beta2^t)`

AdamW 使用解耦权重衰减，参数更新公式如下：

* `params_new = params - lr * (m_hat / (sqrt(v_hat) + eps) + weight_decay * params)`

请返回更新后的参数向量 `params_new`。

你的答案与标准答案误差不超过 `1e-6` 即视为正确。

## 参数说明

* `params`：当前参数向量，形状为 `(N,)`
* `grads`：当前梯度向量，形状为 `(N,)`
* `m`：当前一阶动量向量，形状为 `(N,)`
* `v`：当前二阶动量向量，形状为 `(N,)`

其中：

* `N` 表示参数数量

## 返回值

* 返回更新后的参数向量 `params_new`，形状为 `(N,)`

## 约束

* `1 <= N <= 10000`
* `-100 <= params[i] <= 100`
* `-100 <= grads[i] <= 100`
* `-100 <= m[i] <= 100`
* `0 <= v[i] <= 10000`
* `params`、`grads`、`m`、`v` 的形状均为 `(N,)`
* `grads^2` 表示逐元素平方
* `sqrt(v_hat)` 表示逐元素开平方
* AdamW 中的权重衰减是解耦的，即不加入梯度中，而是在参数更新时额外减去 `lr * weight_decay * params`
* 可以使用基础张量运算或循环实现

## 示例 1

### 输入

```text
params = [1.0, 2.0]

grads = [0.1, -0.2]

m = [0.0, 0.0]

v = [0.0, 0.0]
```

### 输出

```text
params_new = [0.989000, 2.008000]
```

### 解释

由于 `t = 1`，且初始 `m` 和 `v` 都为 `0`，经过偏置修正后：

* `m_hat = [0.1, -0.2]`
* `v_hat = [0.01, 0.04]`

因此 Adam 更新方向近似为：

* `[1.0, -1.0]`

再加上 AdamW 的解耦权重衰减：

* 第一个参数更新方向为 `1.0 + 0.1 * 1.0 = 1.1`
* 第二个参数更新方向为 `-1.0 + 0.1 * 2.0 = -0.8`

所以：

* `params_new[0] = 1.0 - 0.01 * 1.1 = 0.989000`
* `params_new[1] = 2.0 - 0.01 * (-0.8) = 2.008000`
