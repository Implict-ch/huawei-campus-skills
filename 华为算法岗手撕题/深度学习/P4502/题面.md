# 题目描述

你需要实现一个函数，用于计算二分类任务中的 **Focal Loss**。

给定模型预测概率 $p \in (0,1)$（通常为 Sigmoid 输出）以及真实标签 $y \in \{0,1\}$，请你根据下述公式计算最终的 Focal Loss。

### 数学公式

Focal Loss 定义为：

$$
\text{FL}(p, y) =
-\alpha (1 - p)^{\gamma} y \log(p)
-(1-\alpha) p^{\gamma} (1-y)\log(1-p)
$$

其中：

* 若 $y = 1$：

  $$
  \text{FL} = -\alpha (1 - p)^\gamma \log(p)
  $$

* 若 $y = 0$：

  $$
  \text{FL} = -(1-\alpha) p^\gamma \log(1-p)
  $$

**输入参数**

* `p`: 模型预测概率。
* `y`: 真实标签（0 或 1）。
* `alpha`: Focal Loss 平衡系数。
* `gamma`: 调节困难样本权重的指数。

**返回值**

* `loss`: 最终的 Focal Loss。

## 示例

输入：

```
alpha = 0.25
gamma = 2
p = 0.7
y = 1
```

输出：

```
loss = 0.0080
```


## 提示

* $0 < p < 1$
* $y \in \{0,1\}$
* $0 < \alpha \le 1$
* $0 \le \gamma \le 10$
* 对数要求：$p \neq 0,\; p \neq 1$
* $loss \ge 0$
